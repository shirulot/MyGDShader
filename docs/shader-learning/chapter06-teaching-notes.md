### 当前实际参数与输出

- `wave_frequency`：整张纹理纵向的周期数，范围 1～4、默认 2、步长 0.1；当前材质约 2。
- `wave_speed`：正弦时间项的相位速度，单位弧度/秒，范围 0～6.3、默认 3.14159；当前材质约 3.89118。不把它直接称为画面纵向的像素移动速度。
- 固定行的摆动周期由时间项决定，为 `2π / wave_speed`；固定速度参数改变空间周期数，不改变该行的摆动周期。波峰沿纵向的传播速度同时受间距影响，为 `-wave_speed / (2π * wave_frequency)` UV/秒；提高空间周期数会缩小波纹间距并减慢波峰向上的传播。此处为数学核对，不冒称 GPU 测量或学习者独立推导，也不将完整公式推导追加为本节必做。
- `wave_amplitude`：最大横向采样偏移，单位 UV，范围 0～0.02、默认 0.01、步长 0.002；当前材质约 0.02，对应约 10.24 源纹理像素。
- 保存核心：`sin(newUV.y * wave_frequency * 2.0 * PI + wave_speed * TIME) * wave_amplitude + newUV.x`；输出新坐标采样的完整 RGBA。
- 最大横向采样坐标可超出 0～1。Sprite2D 为 Linear、Repeat Disabled，越界会延伸边缘颜色；此前已结合 0.01/0.02 UV 的源像素长度说明。未声称所有越界都消失，也未添加屏幕纹理、第二方向或局部 Mask。
- `origin` 未参与最终输出，旧起点注释仍在；只是可选整理，不作为课程阻塞。
