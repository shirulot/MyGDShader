# 建筑资源生产补充 v002：整栋成品为主

2026-10-06，按用户在技术美术总监chat的新要求及[v001回执](../../art-source/ember/ta-review-v001/building-v001-independent/review-building-v001.md)补充。沿用已选三栋造型和专项尺寸；本文件覆盖v001以细拆件库作为主要交付的组织方式。

## 主交付

每栋必须提供干净透明的闭合整栋PNG、整栋固定主体PNG、实际开发必要的功能合层PNG及可直接使用的预制体。整栋图不能带地板、人物、标签或演示UI。拆件和母稿可保留为辅助来源，完成度按整栋可用结果判断。

同栋所有PNG使用相同canvas/pivot，原生比例1px=1 world，不按各层包围盒重居中或缩放。

## 功能分层

相同绘制顺序内连续固定的墙面、柱梁、檐口、框、格栅、管弯和天线合成静态功能层。后墙、屋顶、前墙、门框及入口面板因前后覆盖、进屋隐藏和淡显规则不同而保留必要层次。风机叶轮及玻璃必须位于固定前景格栅／框之后，故屋顶／前墙可能有背景和前景两个固定层。

门片／卷帘、盖板、内部叶轮、玻璃、状态Mask保持动态。同一遮挡层且使用同一亮暗开关的玻璃合并。门板净口裁切与全开通行规则保持；叶轮只绕原安装轴旋转；状态仅改变独立发光面。

后续新建筑以认可的完整主体统一生成／制作，再按功能拆层，不能分别生成柱梁面板后拼风格。本批使用已审v001图像整数坐标无损合成，不重新生造型；源RGB逐字节核对，默认灯态只有数据Mask按实际GPU四舍五入着色。

## v002修复与验收

读档先恢复玩家，再向所有建筑刷新保存时刻的实际接触盒，最后恢复建筑；防止旧位置使半关门误触发重开。存档玩家实际占用门口时仍执行安全重开，断电状态不移动门片。

组合PNG、必要合层和预制体在同canvas/pivot实拼。逐字节验证合层来源；透明整栋PNG须与闭合预制体GPU逐像素一致。闭合、半开、全开、检修、锁定／玻璃亮、故障、断电、内部遮挡与已审v001实际GPU逐像素一致。复跑148交互、TA原41项及8种保存位置／旧位置／供电组合。新版本另打包、另报SHA，不覆盖v001。
