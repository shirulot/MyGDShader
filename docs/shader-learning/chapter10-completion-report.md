## 实际参数接口、时序和所有权

- `white_flash`：普通 float uniform，本章脚本写0.0/1.0；0使用底图RGB，1使用目标色。Tween 属性路径为 `shader_parameter/white_flash`，set/get 参数名则仅为 `white_flash`。
- `hit_color`：普通 vec3/source_color uniform；GDScript 用 Color，白色(1,1,1,1)，橙色(1,0.35,0.15,1)。Color→vec3 取RGB，A不参与该接口，不是预乘。最终 Alpha 来自底图 `tempColor.a`。
- `gray_progress`：旧声明/保存值仍在，但未参与输出，不冒充灰度驱动接口，不自动清理。
- 当前四个辅助函数：`set_shader_parameter(name,value)`、`tween_shader_param(name,end,time)`、`kill_tween()`、`new_tween()`。所有权由每个实验根脚本持有当前 Tween，写入 Robot 当前材质。
- 空格可见动画0.3秒；C先用0.3秒退份额，再顺序追加0.3秒把目标色归白，整条约0.6秒。后半段份额为0，颜色复位不可见，是有效选择。重触发直接设本次目标色，不依赖旧动画后半段执行完。
- 缓动为 QUAD/OUT，开始退得快、末尾慢；半程份额0.25相对线性0.5是API/静态解释，没有测量半程读数或声称用户推导该曲线公式。
- `kill()` 使 Tween 失效但不使成员自动变成 null，也不替参数归零；当前针对旧引用检查非null且is_valid，每次播放创建新的 Tween。
- `create_tween()` 绑定实验根节点；文档/代码层说明节点释放时动画随之中止，未人为删除节点构造运行测试。
- 10.3 最终 Robot.material 为 `ShaderMaterial_y7p12`，RobotB.material 为 `ShaderMaterial_shared`，各自引用 `Shader_my5h2` / `Shader_gbdts`。文件名中的 shared 仅历史名称，当前是两份不同材质，不能按名字误判仍共享。
- 当前材质/Shader 上部分 `resource_local_to_scene=true` 不单独作为同一场景两节点隔离的原因；本次隔离直接依据为不同材质资源引用。Local To Scene 的跨场景实例行为未额外实践。

## 典型错误与排错过程

1. 对 Sprite2D 调用 set_shader_parameter：用户截图证实运行错误；改对实际 material 调用后正常确认。
2. 用 elif 解释为规避重复：已有 pressed 判断确实过滤松开，elif只互斥按键；教师解释 echo 后学习者补齐重复过滤，保留有效分支写法。
3. C只改目标色/Tween目标色归白而不启用份额：在份额0时不产生可见变化；按当前mix职责解释后，学习者补份额1并Tween份额到0。
4. 在C内创建局部Tween且反向判断有效性；之后成员化但仅null时创建，kill刚建的Tween再向失效对象添加任务。教师追踪当前执行顺序并给局部分支参考；最新每次中止旧有效Tween后新建，故障修复。
5. B未中止旧动画、白色初始化曾缩进在有效性判断内，以及入口创建空Tween，均依据最新保存差异指出并由学习者修正；不捏造每项均曾在画面复现。
6. 自主封装后把kill提升到所有有效键入口，导致非操作键可能中止于中间份额。用户明确接受Demo只用三键的范围，作为延期记录，不强制继续返工。
