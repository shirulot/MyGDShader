# v006 十三材质地板统一标准

新增ID10压实沙土、11灰色碎石、12苔石地坪，扩展干燥矿业、灰色矿区与废弃区域。原十种材质编号、旧砖木周期与公共构造不变。

地板延续低彩度、平整顶视、小像素簇与安静的大色块。沙土为低彩度暖赭色细粒硬地，不画沙丘；碎石为中灰小矿物颗粒，不画大块带投影的石头；苔石保留大量灰石和稀疏灰绿斑，不画高草或荧光绿。均为完整实心底色，孔洞、植物、设备与坡面另属装饰或场景构造。

新表面注册为相同1024周期，纹理按世界格位置连续采样。材质只改变floor艺术像素，不能改变coverage、压顶、立面或桥口。混铺地图须实际含十三种材质，不以示意图代替资源。

验收新增3种与旧10种及两两新材质共33对、横纵66组交界，12个四向桥口；保持全域／局部六层RGBA、撤销存档、旧1～9文件、原生材质输入、负原点重建与context世界坐标一致。F4／F5／F6分别选择10／11／12，F1保留7，方括号可由12回0。技术通过不代替用户的美术判断。
