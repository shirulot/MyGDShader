本文件用于网站生成候选，不修改现有角色或运行资源。用户最新两张正背面参考决定新角色造型；项目规范决定画布、注册、像素语言及UI兼容。第一张为背面，第二张为正面。

## 通用提示词

为《余烬采能站 Ember》制作同一个战斗机器人的原生像素游戏素材。

参考职责：
参考图1是机器人背面，参考图2是机器人正面。两图共同定义同一个角色的正反面结构。
最初提供的 Platformer character pack 只用于参考动作姿态、预备/出招/收势的节奏和清晰像素表现。
把该动作语言重新绘制成项目的轻俯视八方向。镜头固定、正交、无消失点，可看到头顶、肩部上表面和适量正面；所有方向共用同一俯角与相机距离。

角色身份必须固定：
深蓝灰装甲，浅灰金属边缘，黑蓝机械关节，细长双尖角头盔，青色V形面罩。
正面是三角形胸部能量核心，背面是圆形环状核心，两者不能混用。
保留尖角肩甲、分段机械腰部、清楚的肘膝关节、厚实机械足。
能量刃固定安装在解剖学右前臂：正面看位于画面左侧，背面看位于画面右侧。另一条手臂保留普通机械手。
禁止武器换边、凭空增加武器、双臂都装刀、背面出现面罩或正面胸核。
在小尺寸下简化装甲细节，保留参考的识别轮廓和头身关系，不变成旧维修机器人或全新机甲。

项目视觉语言：
低饱和旧工业像素风，清楚色块、克制磨损、小面积高光。材料通常3至4级明暗，原生轮廓以1像素为主。
暗结构色参考#101820、#182631；蓝灰参考#2B3E4B、#4D6470、#829BA3；浅灰装甲边参考#BECBC4和少量#ECE9D8。
青色识别部位靠近#51C5C2，保留用户参考中的用途和位置，不让大面积光晕盖住装甲。
与项目“边缘标记”UI的深蓝灰、米白、青色和克制金属风格一致。角色图本身不画UI、文字、血条、边框或角括号。
禁止照片式反光、光滑塑料渐变、均匀细碎噪点、密集铆钉和厚金属描边。
各方向材质使用相同颜色表；光源始终位于画面左上，不能随角色一起旋转。

最重要的尺寸与注册合同：
每帧固定为64×96原生像素，透明背景，左上为(0,0)，x向右，y向下。
每一帧的地面根锚点固定为(32,80)，它代表世界位置的地面投影，不是包围盒中心，也不是每帧最低的可见脚像素。
正常站姿主体以约40×64原生像素为预算，沿用同一身体尺度、头身比例、装甲厚度和武器长度。
八方向必须是同一物体在同一镜头下每次转向45度：允许合理透视缩短与遮挡，禁止独立缩放各方向来强行填满格子。
所有帧使用同一尺度及坐标变换，禁止每帧自动裁切、重新居中、对齐头顶、齐脚底或按包围盒缩放。
身体和关节可以围绕固定根锚点产生合理动作，不能把整个人物平移当成动画。抬脚和跳跃不能为了齐底而被拉回原位。
任何装甲、脚、尖角或武器都不能被单元格边缘裁断；不能通过缩小某一帧的人物来容纳出招。
左右朝向分别绘制，保留武器侧别和固定光照，不能直接镜像或旋转成品。

像素与透明格式：
真正的原生像素网格，无抗锯齿、模糊、混色柔边。
实体层Alpha只使用0或255。无背景、地板、投影、装饰底色或绘制的棋盘格。
外发光、斩击轨迹、火花和冲击效果另层，不与机器人轮廓合并。
若网站只能输出大图，整张图统一整数放大，所有布局坐标同比例放大；不得分别缩放每一格。
提示词与大尺寸输出只是候选输入，原生像素成品还需检验。

## 任务A：八方向静态母版（接在通用提示词后）

本次只生成同一机器人八个方向的中性战斗站姿，每方向一张，共8张。
布局为4列×2行，无外边距、无格间距。
原生总图256×192；若必须大图，则严格4倍输出1024×768，每格256×384，根锚点对应(128,320)。

第一行从左至右：down/S正面、down_left/SW前左、left/W左侧、up_left/NW后左。
第二行从左至右：up/N背面、up_right/NE后右、right/E右侧、down_right/SE前右。

所有方向使用同一中性站姿，双足支撑、轻微屈膝、双臂自然准备，右前臂能量刃处于安全低位。
所有格子的根锚点为(列索引×64+32, 行索引×96+80)，索引从0开始。
不同方向投影宽度可以自然变化；角色体量、头部大小和骨段长度必须一致。
不要画任何标签、网格、数字、地面或UI。

## 任务B：单方向行走（替换任务A）

本次只制作down_right/SE方向的walk，所有帧都朝右下，不是转身图。
8帧，4列×2行，固定格与总图尺寸沿用任务A。规划播放8FPS，循环1秒。
帧序：左脚接触、左支撑下沉、右脚经过、右脚抬升、右脚接触、右支撑下沉、左脚经过、左脚抬升。
原地完整两次换步，尾帧自然接首帧，不复制首帧，不倒放凑循环。
动作参考原网站清楚的重心转移和关节运动；机械臂、肩甲与武器有受控惯性。
髋、大腿、膝、小腿、踝和脚形成连续机械结构，真实屈膝。装甲保持刚性，不拉伸、变形或散件。
根锚点不移动；足部相对根节点按步态运动。不要把所有支撑脚固定在同一画面位置。

## 任务C：单方向挥斩（替换任务A）

本次只制作down_right/SE方向的一次右前臂能量刃挥斩，8个连续关键帧，4列×2行，固定格尺寸沿用任务A。
这8帧是本次新战斗动作提案，不是项目已有帧数规范。
帧序：战斗准备、屈膝压低重心、肩髋蓄力收刀、快速挥出、最大随动、减速回收、恢复支撑、回到同向准备姿势。
靠近原网站的动作表现：清楚预备、短促释放、明确打击姿势、充分随动和可读收势；不是每帧匀速挥手。
机械身体由髋与肩驱动，肘膝真实弯曲，右前臂刀与手臂保持固定安装关系。
不为模仿原人物添加头发、裙摆或披风。装甲和武器不弹性变形。
本体图不画斩击光弧。出招全程不换朝向、比例或根锚点，保持整把武器在格内。
播放节奏在生成后另行登记，不能用一张静态图宣称已经完成动画或精确帧率。

## 通用负面提示词

错位图集，不等大单元格，逐帧缩放，独立居中，根节点漂移，自动裁边，对齐每帧脚底，头部忽大忽小，方向间体量变化，斜向角色变大，镜头倾角变化，武器换手，左右镜像，前后核心混淆，背面长脸，零件增减，关节断裂，细线接肢，机械护甲拉伸，脚掌折叠，重复站姿冒充走路，双腿不换步，照片质感，3D渲染，模糊，抗锯齿，渐变底，棋盘背景，烘焙光晕，地面阴影，文字，水印，UI面板。
