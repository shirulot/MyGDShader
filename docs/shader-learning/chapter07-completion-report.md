## 典型排错与保留的有效实现

1. 从灰度观察切到透明描边时，曾沿用最终Alpha固定1及RGB乘Mask；用户说明是沿用了上一阶段要求。教师明确输出职责变化，随后修正，不记录成永久不懂Alpha。
2. 原图合成曾用灰度作为mix终点、总Alpha作为颜色权重；后改为原RGB/轮廓RGB及轮廓所占Alpha份额。
3. 只采远端或循环中直接覆盖，会漏掉一像素细线。两份累计最终都使用跨轮max；07.2 因宽Mask仍存在，错误期间细线近旁回落为约0.6外圈，而非完全透明，解释中区分了这点。
4. 分母保护仅用于除法，不能把最终总Alpha整体抬到epsilon。0.0001与教师示例0.00001均接受。
5. float 半径配整数步长1、max参数交换顺序、border_color命名均有效。d=0曾为日常编码习惯、只产生冗余采样，不当作视觉错误；当前均从1开始。
6. 07.1/07.2 少量旧注释尚与输出不符，属于可选整理，不作为结课阻塞。没有为了整理改写学习者代码。
