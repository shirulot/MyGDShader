# Godot Shader 进阶课程

建立日期：2026-10-21。

来源：用户在课程深度讨论后明确要求：“我希望后续也加入一些高级课程 可以再整体结束后 增加一份进阶课表”。

这是现有 [C01～C16 主课程](curriculum.md) 整体结束后的续学规划，包含 **4 个 Phase、12 个 Chapter、36 个 Section**，编号 A01～A12。规划已建立，教学尚未启动；当前教学位置仍由 [progress.md](progress.md) 管理。C 系列仍为 16 章 / 48 节，进阶不混入当前完成率，也不改变当前 C/M 调度。

这里的“整体结束”指现有 C 系列学习与验收结束；原有可玩学习项目的应用义务继续单独登记，不要求商业游戏发行后才能进阶。开始 A01 前由统合者复核主课程验收、遗留复习与应用安排。

2026-10-21游戏时机补充：依用户“游戏接入不急 我说需要时再说”，伴随游戏实际接入仅在用户明确提出需要时安排，不因C/A结课自动启动。A课程所需最小可交互测试场属于教学实验，照常学习；实际项目应用另记待办，不取消全效果覆盖义务。

## 定位与教学约定

主课程建立常见游戏效果的实现能力；进阶课程进一步训练采样质量、数据与坐标重建、光照模型、多通道处理、空间积分和有状态 GPU 计算。部分作品会再次做水、火焰、护盾，但增加明确的新知识与质量要求。

- 沿用 [学习需求](requirements.md) 和 [长期教学偏好](learner-preferences.md)：学习优先、每次一个小目标、新概念先讲局部方法、学习者编写关键逻辑。
- 每节引入 1～2 个核心概念；表格是一节的最终范围，可拆成多个小实验，不在一个教学回合全部讲完。
- 每章都有基础对照版、可视调试与边界检查。成熟度来自能解释、修改、诊断和测量，不以代码长度或效果层数验收。
- 数学跟随画面：导数从边缘宽度学，积分从沿射线累积学，离散模拟从相邻格子的更新学。必要补课不视为已掌握，也不删除目标。
- 根据独立作品证据合并熟悉内容；“见过效果”或“改过参考”不能代替新知识验收。
- 本表是可执行的初版规划。进入每章前按届时作品、Godot 版本、渲染器和硬件细化，不提前承诺固定课时。

## 依赖、资源和进入条件

默认按 A01→A12 顺序推进。A03 与 A02 无直接依赖，可依据作品调整；A05 不强依赖 A04，但都要在环境综合课前完成。后续只能基于验收证据调整顺序，不能因当前游戏用不到而删除内容。

- **资源：** 优先复用现有噪声、测试纹理、机器人、地板及简单几何体；Flow Map、SDF 测试图、河道、雾盒和模拟网格按章准备。这里列的是需求，不代表已经生成或许可审核。实际新增资源进入 [resources.md](resources.md)。
- **渲染环境：** 本表不要求立即切换项目渲染器。深度约定、缓冲可用性、HDR 和后处理接口在开章前按安装版本核验，必要时用独立最小实验项目，保留当前学习工程。
- **Compute 条件：** 官方文档说明计算着色器依赖 RenderingDevice 渲染器（Forward+ 或 Mobile）；不能假定 Compatibility 可运行。若届时设备不满足，记录阻塞或准备合适实验环境，不以 CPU 演示冒充 GPU 实操。[Godot：Using compute shaders](https://docs.godotengine.org/en/stable/tutorials/shaders/compute_shaders.html)
- **空间重建：** 深度线性化与重建必须与实际渲染器的投影约定对应；进入 A04 时用已知位置做验证，不直接照搬其他版本公式。[Godot：Advanced post-processing](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html)
- **脚手架：** 允许教师准备非本节目标的最小资源创建、读写连接或测试入口，清楚标记职责；Shader 核心与被列为学习目标的数据调度仍由学习者掌握。

## 应用与完成标准

原有 [48 小节应用矩阵](game-effect-coverage.md) 保留原编号和验收范围。进阶新增的火焰、雨、水体、风场、体积和模拟等具名效果，同样规划真实可玩用途；导数、过滤、重建、BRDF 等知识可共同服务一个功能，不机械新增 36 个游戏功能。

在进入 A 系列时，统合者建立独立的 A 系列应用台账，逐项记录用途、文件、事件接口、代表性运行证据和未完成项。暂时不适合商业作品的内容先进入可玩学习测试场；实验通过不等于应用通过，商业发行版取舍另行评审。

四个阶段出口分别是：

1. 能解释并改善缩放/运动中的采样问题，独立构造程序场与 SDF。
2. 能验证坐标和深度，解释光照模型，制作方向与混合关系正确的材质。
3. 能管理中间图像与历史状态，实现可拆层检查的水体和天气环境。
4. 能解释体积近似和 GPU 状态更新，提交有性能证据及可玩应用的综合作品。

此路线进入游戏技术美术和实时图形进阶，但不是渲染研究全覆盖。完整 TAA、SSR/SSAO 系统、FFT 海洋、完整流体求解、路径追踪和引擎级渲染管线改造可作为后续专题；本次不把它们包装为上述小节已经覆盖的内容。
