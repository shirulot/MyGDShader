# Godot 游戏 Shader 完整课程

本课程包含 6 个 Phase、16 个 Chapter 和 48 个 Section。它从 2D 可见实验开始，经由组合效果和游戏逻辑，最终进入 3D 综合视觉效果。

## 阅读说明

每个 Section 原则上只增加 1～2 个核心概念。表格中的“旧知识”用于提醒章节 Chat 做迁移，不代表学习者已经熟练；“完成标准”必须通过实际运行和解释验证。

2026-09-27 增加[伴随课程小游戏路线](game-project.md)：学习实验逐步接入《余烬采能站》。现有章节编号与验收标准保持有效；第一章验收后可先搭建可玩骨架，Chapter 10～11 再正式学习并接管脚本驱动。小游戏接入是实验的应用，不另行增加48项游戏功能。

2026-10-01 应用目标升级：用户要求学习游戏实际覆盖全部效果。新增 [48 小节游戏应用矩阵](game-effect-coverage.md)，由 2D 学习版与小型 3D 可玩项目共同承载，不再以“仅留实验”结束应用。原章节编号、依赖、单概念实验和独立作品标准保持；16.2 二选一与 16.3 三选一用于确定深入主作品，不免除其余具名效果的代表性游戏应用。多个效果可复用同一任务，应用验收与课程掌握分别记录，M0 当前范围不变。

## Phase 2：Mask、Noise 与采样变形
