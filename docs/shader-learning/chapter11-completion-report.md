## 当前接口、参数与所有权

### 事件及状态

- `DamageProxy`保存 `max_hp=100`、导出的 `hp`；正常入口是满血初始化。
- 模拟受击按钮进入 `_on_simulate_damage_pressed()`：HP<=0则返回；否则减25并限在0～100，先发送 `health_changed(hp,max_hp)`，再根据是否仍存活发送 `damage()` 或 `died()`。
- 以HP0作为本次一次性死亡守卫有效；没有要求额外布尔字段。本流程没有回血、重置或复活接口。
- `HitVFX`通过相对路径定位同一场景实例内的Robot、HPLabel和DamageProxy，并在_ready连接三个信号、主动同步当前血量。
- `_update_hp`以 `clamp(1.0-hp*1.0/max_hp,0,1)` 更新危险程度。最终版HP0时先更新Label再返回，保留最后存活时的色偏用于溶解；不会在零血继续写入危险程度1。此前11.2阶段零血映射1的实现/审查证据与最终死亡交接分别记录。

### Shader接口与输出

| 参数 | 类型/本次用途 | 初态及变化 |
| --- | --- | --- |
| white_flash | float；瞬时受击混合份额 | 保存0；每次受击设1，用0.3秒退到0；死亡中止未完成受击时清零 |
| hit_color | vec3/source_color；受击颜色 | 白色RGB(1,1,1) |
| danger_progress | float；持续低血色偏份额 | 保存0；存活时随当前HP更新，不参与受击Tween |
| low_hp_color | vec3/source_color；低血目标色 | RGB(1,0.35,0.15)；按当前份额直接混色，教师半份混色建议未强制采纳 |
| noise | sampler2D；线性灰度阈值数据 | D04低频Noise，读取.r；最终已去掉source_color |
| dissolve_progress | float；本成品定义1完整、0消失 | Shader默认1，材质保存约0.999999977648；死亡显式设1，用1秒退到0 |

最终RGB为“原图与低血颜色混合 → 与受击颜色混合”。Alpha为原图Alpha乘Noise阈值Mask；进度恰为0时明确Alpha0。进度方向与C05原接口相反，不可把原材质的0初态或0→1驱动直接套入此成品。当前没有edge_width接口，也没有溶解边带；C05完整边带仍是旧章已学作品，不在C11重复补做。

### Tween、材质和生命周期

- 每个HitVFX实例持有自己的Tween引用；普通受击与死亡都先处理旧Tween再新建。
- 普通受击终值是white_flash=0；致死时停止仍有效的受击Tween并清零其份额，随后死亡Tween只驱动溶解进度。HP守卫阻止死亡中再次受击/重启溶解。
- 死亡Tween.finished连接_on_death_finished；只有动画结束后才设置 `robot.visible=false`。Shader全透明与节点隐藏作为两个状态分别处理。代理、Label和按钮仍在树中，当前没有释放根节点。
- ActorA/B复用同一PackedScene、同一脚本及同一Shader程序；两份ShaderMaterial不同，源材质 `resource_local_to_scene=true`。只读纹理可以复用，不要求复制两套Shader或动态duplicate。
- F6新运行/新场景实例使用保存初态：满血、可见、白色份额0、危险程度0、溶解进度约1。没有实现同一存活实例的隐藏后复活或对象池重置。
