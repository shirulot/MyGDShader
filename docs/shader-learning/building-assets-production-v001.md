# 三栋建筑正式资源生产规范 v001

日期：2026-10-06。以用户选中的控制塔、维修工坊、物流仓库及[拆件清单](../../assets/ember/buildings_final/docs/selected-buildings-breakdown-v001.md)为依据。完整尺寸继续遵循[建筑规范](ember-building-standard-v001.md)。

## 本轮资源与边界

正式游戏视角为零yaw的南向复合俯视；技术三视图保留为设计依据。本轮生成三栋可复用建筑南向组装、28份原稿和登记部件，不新增完整室内玩法。外部地板由已有128纹理／32世界格／0.25笔刷绘制，建筑独立Sprite为1px=1world。墙／屋顶固定预制模块不标记建筑Terrain通过。

墙壳、屋顶、柱与檐口、窗框、门框、格栅、管弯、天线外壳为静态资源；活动门板／卷帘、检修盖、内叶轮、玻璃、控制面板与状态发光面单独登记。同栋共用原点，局部部件经pivot恢复安装点。静态大面内的柱和檐口保留同源像素裁切能力，不能旋转烘焙光照冒充另一方向。

## 注册与审查

规格源为[source_specs_v001.json](../../art-source/ember/building-assets-v001/source_specs_v001.json)。原稿、完整提示词、引用职责与SHA256保留。仅裁切、保持比例的Nearest、固定画布和Alpha洞口／数据遮罩；不程序重画RGB、不随机撒噪点、不强制量化颜色。门窗净口以机械Alpha几何保证，开闭叶片使用同一原稿在引擎裁切运动。

静态实体为二值Alpha、外圈透明、固定画布／pivot。门净口、落地阈线、64×64门前通道、三栋尺寸、窗格／双天窗／仓库两条内部肋、普通门与货门、风机内外层、开关中间态／遇阻／锁定／断电／故障、进入与屋顶遮挡、独立审阅工程导入逐项验收。视觉原稿、PIXEL_FINISHED和ENGINE_PASS分开记录；技术检查不能代替用户参考风格审阅。
