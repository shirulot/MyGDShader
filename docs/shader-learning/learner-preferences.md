# 长期教学需求与偏好

更新：2026-10-07。用于本项目的 Shader 教学、游戏开发复习和统合调度；跨章节累积，不在换 Chat 时重新归零。它记录学习者希望如何协作，不替代 [课程掌握与应用进度](progress.md)，也不据此判断性格或长期能力。

## 维护授权与范围

用户明确要求：“后续每一章结束后，你都让他们采集我的习惯来完善你下一次分章节”；随后补充：“我的意思就是我的习惯用于长期，这样可以逐渐完善我的需求让你更了解我。”

每章教师在正常教学中记录相关反馈，结课报告必须包含习惯/需求反馈；统合者核对并持续更新本文件、学习需求和下一章交接。独立游戏教学结束时同样采用这套交接。不要增加每节问卷、反复问已经明确的偏好，或为了收集反馈延长已完成章节。

2026-10-07 用户补充：“后续如果章节结束记得让子chat自动回来通知你让你继续调度”。现已授权本课程教师结课主动向指定统合者发送报告，统合者核对后按既定路线续调度；普通结课不再等待用户传话。范围、来源人类消息与收件方见 [自动交接协议](handoff-protocol.md)，不授权教师自开章或扩大商业/游戏范围。

## 当前长期有效的规则

1. **优先级与覆盖。** Shader 学习最高优先级。游戏、美术或商业范围不能删课程；全部具名效果最终在可玩学习项目中应用，课程掌握、游戏应用、商业验证分开。依据：2026-09-27、10-01 的明确要求及 requirements.md。
2. **熟悉与新概念分开。** 已教过或明确熟悉的内容，先给精确需求和文字方法，让学习者写，未求助不主动贴已学公式/代码；新概念先讲含义、输入输出与做法，必要局部 API/参考及时提供。依据：C03 明确反馈，见 chapter03-teaching-feedback.md。旧“先自行试，不懂再问”不适用于尚未讲清的新概念。
3. **需求要具体。** 每次写清对象、数值、单位、变化方式、预期画面和当前一步的验收。用户要求“具体点”不等于索要代码。依据：C03 原话“每次列需求都应该具体点”。
4. **节奏与数学。** 一次一个小目标，数学一次一个小概念，用数字、像素距离和可见结果解释；不从接触过 vec/mat 推定已经理解。用户自行实现关键逻辑，教师可以准备最小场景/材质和默认采样起点。依据：C02/C03 交接与明确反馈。
5. **审查与推进。** 先读最新保存文件；“好了/写完了”及写后审查按用户已经正常运行确认处理，不重复追问同一画面或编造测试次数。给出具体评论：当前小步无问题再给下一小步，有问题停留排错；Section 切换仍按确认规则。依据：M0/C03/C04 反馈，C04 明确原话“审查完之后给出评论 如果没问题直接继续下一步 有问题在停留”。
6. **保留有效选择。** 区分真实错误、静态风险、可选整理和延期；保留已验证的替代实现，不因命名/风格不同返工，不在收尾无限追加挑战。依据：M0/C03/C04 的已接受方案与 requirements.md。
7. **游戏和练习的素材选择。** 游戏默认用自制像素机器人与新地板；练习由教师按概念选材，适合时可试用新素材，测试图仍用于清晰对照，不为换图中断已开始练习。依据：2026-10-06 统合 Chat 三次明确补充。当前文件入口以 resources.md 为准，不把版本号当成永久偏好。
8. **调度职责与主动交接。** 章节教师只完成本章，结课按授权自动将报告发给指定统合者；由统合者核对后选择后续 C/M 并新开一个 Chat，普通结课不需用户再次传话/说继续。依据：C04 调度纠正及2026-10-07本 Chat 的明确补充，见 handoff-protocol.md。教师不得自行开章；这不取消 Section 确认、不新增任意跨 Chat 消息权限、轮询监控、自动代写或商业扩展。
9. **长期累积。** 每章回收并更新需求/习惯，下一次分章节读取完整现行记录，而不是只带上一章的几句话。明确的新要求修订旧规则，保留来源与修订原因。依据：本页维护授权。

## 已采纳的教学方法改进

- C04：每一步明确旧逻辑哪些保留、哪些替换、哪些仅注释留档，以及最终输出由什么构成；复用旧代码时先说明本步实际需求、复用输入与职责，不只说“复制上一章”。这是针对本章切换困难采纳的教学方法，不包装为性格判断。
- C05：先用一句话说明本步输入将服务哪个可见效果，再拆小目标；不要把明确目的拆成一长串失去联系的调参。数字例子标注“Inspector 参数 / 某位置采样值 / 单位”；替换函数时说明下游判断和输出哪些要同步改变。依据 [C05 反馈](chapter05-completion-report.md#长期需求习惯反馈)，作为教师方法改进，不推导不喜欢理论或永久能力不足。
- C06：分开说明“采样坐标 → 读到的颜色/Alpha → 输出”，数字标源纹理像素、UV 与显示距离；一次只处理一个关系，再接下一步。依据 [C06 报告](chapter06-completion-report.md)及[教学记录](chapter06-teaching-notes.md)，同轮混讲相位/坐标/偏移不利于当前理解，拆开与源图采样位置查证有效；纳入教学方法改进，不将暂时困难当永久数学能力。C07 先复习 Alpha，再单方向邻域，保留全部核心内容。
- 没有新增用户偏好的章节，写“无新增，沿用现行规则”，并可指出哪些已有规则本章再次有效；不强行制造新习惯。

## 每章必须交付的习惯/需求反馈

```text
章节 / 日期 / 来源 Chat：
新增或再次确认的明确偏好（用户原话 + 上下文；无则写无）：
有效教学方式与应避免方式（具体互动及效果）：
旧规则的修订 / 撤销 / 适用范围变化（无则写无）：
仅本章观察、待确认项（不得直接当作长期习惯）：
下一章可执行调整（目标颗粒度、讲解、提示、审查、复用、资源等）：
统合处理：待核对 / 纳入长期 / 方法改进 / 仅近期观察 / 不采纳；理由：
```

明确用户要求可以直接纳入；教师观察先标为观察，多章证据一致或用户确认后再推广。一次卡住、用了参考、文件回退原因未知或某个概念尚未独立解释，只进入进度/复习记录，不推断“数学差”“没耐心”等长期属性。冲突优先采用最新明确要求；只有影响教学选择且仍不清楚时才简短询问。
