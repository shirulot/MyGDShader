## 使用方式

按以下流程推进课程。统合者只维护路线和状态，章节 Chat 负责实际教学。

1. 在 [学习进度](progress.md) 中确认下一个章节及其前置条件。
2. 从 [章节 Chat 模板](chapter-chat-template.md) 复制启动提示词，并填入当前章节信息。
3. 在新的章节 Chat 中完成逐步实验、练习和复盘。
4. 章节教师结课同轮自动将包含长期需求/习惯反馈的报告发送给指定统合者；没有新偏好也写明无新增，不等待用户传话。
5. 统合者核对并更新进度、长期偏好、资源台账，按既定路线新开下一段C/M，带入完整现行规则与本轮变化；重要待确认选择仍询问。
