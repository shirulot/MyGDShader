# 敌人八向动作扩展规范 v002

来源：用户在技术美术总监会话的新授权（2026-10-06）：通过前置验证后补齐序列帧及八向。基准为已正式通过的 v012 四敌人正向五动作。历史验收保持有效，八向新增资源另行审核。

## 范围和阶段

四单位各八方向×五动作，总160条/960帧。其中down原有20条/120帧逐字节保留，新增140条/840帧。

阶段一：四单位八向中性造型对照＋每单位down_right移动八帧小样。两者经TA批准后才批量扩展其他新方向与动作。方向母版是固定零件的来源；不能把AI逐帧重设计当动画。

## 方向与固定约定

方向顺序：down(S)、down_left(SW)、left(W)、up_left(NW)、up(N)、up_right(NE)、right(E)、down_right(SE)。每45度一档。统一轻俯视正交镜头和画面左上光照，保留浅甲、蓝灰骨架、少量黄铜及原生比例。

128×128透明画布，根/地面投影点(64,104)，Nearest。方向注册可以在母版阶段一次明确校准，记录源格/缩放/偏移；同方向所有帧共用该校准，禁止逐帧bbox归一化。

不同批次生成的源图可能具有不同的格子分辨率。每张源图必须记录一次共同的等比像素密度换算，并用已通过角色的原生尺寸校准；同一源图内所有视图共用该比例。禁止分别缩放头、躯干、风扇或单个方向来掩盖造型偏差。此注册只在静态母版阶段进行，仍须提交跨方向对照让TA审核，不能据此继承旧方向的通过结论。

巡逻兵解剖学右臂枪、左臂夹爪；切割者右工具圆锯、左工具夹爪，另有四条行走腿；重型双履带单短炮；无人机双风扇/双电机/每转子四叶。工具侧别按角色本体判断：down时右工具在屏幕左，up时在屏幕右。侧向允许合理遮挡，但要登记被哪一部件遮住，不得靠镜像交换非对称武器。

新方向不直接旋转整张正面图或水平翻转作为交付。原有三视图/拆件图指导隐藏面，必要补图一次固定后使用；无人机基准仅已通过v011，不纳入未审probe-neck实验。

## 实现与校验

沿用固定源纹理区域、刚体和关节位姿导出。柔性/伸缩连接件必须命名、限定源区域和端点；壳体、武器、护板保持刚性，不可被拉伸替代新视角。

保留生成原图/完整prompt/引用角色、方向母版、部件归属与注册数据。生图输出先判断身份/侧别/部件数，再检查本方向原生像素与动画，不能只看漂亮大图。

每批提交透明PNG、图集、SpriteFrames、版本与SHA、全帧深浅底1×/4×联系图、正常/1FPS运行和Godot八向切换演示。切换使用原frame及frame_progress保持相位，不调用不存在的AnimatedSprite2D.advance。

检查脚/履带接地、悬浮到落地高度、关节厚度与遮挡、工具和转子拓扑、动作循环、相邻方向同相位切换及预览ROI全覆盖。没有母版或尚未制作的动作显示“未制作”，不能用镜像或静态帧填充并计入完成。

新增方向不得继承down美术PASS；每批绑定固定版本提交技术美术总监。全八向通过后才能标160/160，不影响v012已通过状态。
