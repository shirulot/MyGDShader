# 建筑接合规范 v003

用户于2026-10-06指出v002实际拼装屋顶与墙体对不齐、屋顶明显大一圈。本规范修正旧生产尺寸中的错误，不以旧图一致性作为外观验收。

1. 同栋以墙体承重轮廓为共同基准。当前三栋无结构依据的8px四周挑檐取消，屋顶左右边界与墙宽完全一致；保留的倒角属于边界内结构。
2. 南墙接地中心为pivot；屋面前沿接合线为`y=-wall_height`，后沿为`-wall_height-footprint_depth`。屋顶贴图的前檐立面额外向下投影8px，其画布深度为`footprint_depth+8`，与屋面平面深度分开登记。按实际Alpha与墙顶交叠检查无空缝，不能直接把透明画布边当作接合边。
3. 屋顶肋条必须与下方承重柱轴相接，仓库两条轴统一为`x=-59,+59`。平面宽度服从结构轴，不把结构轴跟着各自独立图片的比例移动。
4. 边框和结构肋条保留原生宽度，只登记其间的平面尺寸。颜色、旧化、光照沿用原图；禁止靠缩放整栋预览或加遮盖条隐藏误差。
5. 修正进入正式完整透明图、固定主体、功能层与交互预制体。闭门、开门、检修等状态不得有不同建筑轮廓。旧存档顺序修复保留。
6. 必须提供同尺度修前/修后实拼、墙边与接合线辅助图、无标线原生/整数放大图，人工看清接缝后再送审。测试须检查接合几何及真实渲染；“新旧零差异”仅用于不应变化区域。
