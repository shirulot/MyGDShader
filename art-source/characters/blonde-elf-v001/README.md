# 金发妖精剑士 v001

2026-10-13，使用内置 image_gen 生成的原创角色试作。妖精暂按成年尖耳精灵、无翅膀处理；造型为金发高马尾、绿色轻装、单手剑。

## 文件

- `01-eight-directions.png`：4 列 × 2 行的八方向站姿样张；读取顺序为南、西南、西、西北、北、东北、东、东南。
- `02-walk-southeast.png`：4 列 × 2 行的东南向走路动作样张。
- `03-slash-southeast.png`：4 列 × 2 行的东南向单次挥剑关键姿势。
- `prompts.md`：原始生成提示词与像素修订提示词，包含未选用的第一轮角色设计提示词。

## 当前验收

三张图均为 1536×1024 RGBA PNG，已确认存在真正的 alpha=0 透明背景区域。原始 alpha 范围为 0–254，保留工具原始输出，未作像素或透明边缘清理。

角色大体保持同一造型，八方向具备正面、侧面和背面。挥剑样张具有预备、挥击和收势阶段。

这些文件是生成试作图，尚未通过游戏动画验收：走路左右脚交替不够清晰；脚底锚点和比例存在波动；像素网格仍有不一致、细节密度高于目标参考；八方向俯视倾角还需统一；挥剑第 5 格的剑身受特效遮挡。尚未裁帧、设置帧时长或接入 Godot，不能把 4×2 布局直接视为已经可循环播放的动画。

本目录用 `.gdignore` 隔离原稿，防止当前 Godot 教学工程自动导入试作图。
