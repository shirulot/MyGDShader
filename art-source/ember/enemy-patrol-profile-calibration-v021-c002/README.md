# 巡逻兵 W/E 腿部校准 C002

仅申请双向中性造型与腿部拆件闸门，不提交新动作或宣称 P21 移动通过。对应 P21 v001 靴形和材质两个 P2。

保留原 S002 头胸双臂工具；近腿的膝甲、胫部和靴直接取原同方向可见源像素。远腿是这些同朝向零件的第二个物理实例，W 固定偏移(-3,-3)，E 固定偏移(3,-3)，不镜像、不过滤、不重新画颜色。髋部闭合连接使用原本方向 2×2 暗蓝灰纹理和固定端点，覆盖在原甲片后面。两个腿实例明确登记；不再使用 v001 那张亮蓝、方平靴底母稿。

相对原静态母图，W 修改 49 个 RGBA 像素，E 修改 50 个，全部在腿部及远腿遮挡区域；最低接地行 y103 与原图逐像素一致。W(66,94)/E(59,94) 的原胫部颜色保留。原近靴的蓝灰层次、黄铜踝与收拢下缘保留。完整近腿形状由 cap/shin/foot 三个原源选区及原色连接件装配成闭合形状；保留的 source PNG 未改动。

source/ 是原 W/E 母图；output/neutral_* 是新候选绑定，*_near/*_far/*_body 是实际装配拆件（每个 128×128，相同原生画布与偏移）。qa/original_candidate_2x.png 行 W/E，列浅底原/候选、深底原/候选。网页可切换 W/E、1×/4×与深浅底，并显示实际拆件。

calibration.json 是所有来源多边形、固定偏移、连接件 UV 和端点；export.gd 可独立重建。新增腿要先由总监确认身份与闭合面，才会重导动作。P20、S/SE 和其它已通过文件未改动。
