# A 右下行走：小幅弯膝 v007

针对用户“膝盖幅度过大”修订。保留 v006 静态分件、关节结构、骨长、绘制顺序和画布注册，修改可编辑步态参数。没有重新生图或逐帧修补贴图。

| 参数 | v006 | v007 |
|---|---:|---:|
| 抬脚最大高度 | 6px | 1.5px |
| 脚前后目标跨度 | 12px | 8px |
| 身体下蹲基量 | 2px | 0.8px |
| 上下起伏振幅 | 0.6px | 0.25px |
| 最大画布投影屈膝角 | 105.15° | 68.77° |

屈膝角 0° 代表伸直，是本绑定的二维投影测量，不作为人体三维关节标准。没有直接截断膝角：通过脚轨迹与髋部高度让固定骨长自然产生较小的弯曲。摆臂系数随步幅调整，保留原有摆臂角度幅度。

## 验证

骨长误差小于1.1e-14，所有行走采样的髋踝距离在可达范围内；双腿支撑采样点分别叠加世界位移后重合。每周期位移相应改为 `(16,5.6)`，不能继续使用 v006 的 `(24,8.4)`。

导出二值alpha、17色、8唯一帧、末帧不复制首帧；根节点始终 `(32,80)`。已观察8帧接触表，过度屈膝明显降低，仍保留分件旋转观感；本轮只修正幅度。
