# 其他美术素材的原生像素断裂复查

本次只读检查 **41 张生产 PNG：建筑/物件19张、UI15张、VFX及3D美术输入7张**。机器人、三张瓦片图集与40张技术数据图由团队其他审阅者负责。

本范围没有发现已确认的机器人式像素断裂，未留下未解决的可疑点。每张图都实际查看了原生1×和最近邻4×，逐像素检查 Alpha 连通、透明孔和孤立区域；结论没有沿用旧验收报告的 PASS 标记。

40张生产图与各自原生 finished 源PNG逐字节相同。18个后期建筑/物件重新使用真实分层PNG合成后，与生产PNG的Alpha及可见RGB差异均为0。采能站旧底图没有分层源，不冒称做了分层重建。

需要保留的设计包括：采能站及继电器两侧管路与本体间留空、壁灯电缆弯环、开启门洞、屏幕九宫格空心、校准物件穿孔、工具箱手柄槽、通信波瓣/传送箭头留空、泡沫溅沫小团和草叶间隙。它们在 `independent-other-art-review.json` 中有原生坐标和逐张说明，不应统一填孔。

草叶为1px斜线阶梯：4邻接统计有9片，8邻接是同一株，根部末行仍会合。泡沫有7像素单独溅沫，符合断续泡沫带语义。41张Alpha均只有0/255，没有半透明杂边。
