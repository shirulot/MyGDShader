## 对正式回执的修正

回执：`art-source/ember/ta-review-v001/enemy-patrol-v002-independent/review-enemy-patrol-v002.md`。

1. **膝甲扁带。** 原来的膝甲与暗胫不再共用同一个缩短区域。两块膝甲从同一原生母稿各取一次，作为保持原生体积的硬壳罩，只移动到登记膝关节；暗胫在后方按投影缩短，足部保留原踝袖与靴口套叠。膝关节登记移至甲片中心(57,90)/(71,90)，矢状面两骨长度调整为13/13；仍需TA确认视觉体积、遮挡和步态自然程度。没有逐帧补块或另生角色。
2. **真实骨端映射。** 在rest骨自身基底中做纵向映射，矩阵将源端点精确送到目标膝/踝；不再先缩局部Y再旋转。导出运行中断言误差小于0.0001。所有部件实际矩阵basis_x/basis_y及目标关节都随catalog交付。
3. **PNG预乘RGB。** 透明Viewport读回明确转换为普通PNG直通Alpha再保存，atlas和内嵌SpriteFrames使用同一转换后帧。实体材质目前规定0/255覆盖，因此可见像素无需反除；若以后恢复连续Alpha，8位反除可能有舍入损失，不能声称任意原字节可逆。没有仅在播放器补偿。
4. **实体覆盖。** 原始PNG保留全部RGBA，独立entity_cutout.gdshader规定0.5硬覆盖阈值，最终八帧为0/255。该规则仅解决实体覆盖格式，不等同手工像素精修；轮廓和色簇最终仍由TA审查。未将透明度处理当成解决P1的替代方案。
