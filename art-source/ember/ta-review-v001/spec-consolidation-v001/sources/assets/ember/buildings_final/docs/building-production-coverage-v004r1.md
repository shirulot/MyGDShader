# 建筑 v004r1：生产覆盖与演示反馈

此次只处理技术美术v004回执的两项P2：正式实体Alpha格式、演示UI越界。v004已恢复的完整造型、母图、门洞、碰撞、脚印、锚点和缩放全部保留，v004 ZIP继续冻结。继承`building-intact-master-v004.md`的连续主体规则。

## 共享生产覆盖

每栋从未改的v004母图定义一次覆盖：源Alpha大于等于128属于实体，导出Alpha255；其他像素导出RGBA全0。实体内RGB与母图逐字节相同，不使用腐蚀、膨胀、柔化、描边、补缝、重绘或局部拉伸。覆盖图随生产完整PNG交付。

所有必要功能层从同一生产PNG按原有区域分配像素，因此不会各自阈值出不同边缘。完整PNG与所有功能PNG的Alpha只有0/255。图像覆盖与地面碰撞无关，门净口和防夹区域不变。

运行时使用Nearest。普通完整实体保持硬覆盖，进入建筑的整壳0.14淡出是既定遮挡效果，不能误称为楼层/房间分区。灯面与玻璃亮度变化继续保留；当前未增加照亮地面的实际光照。

覆盖统计是格式证据。另查看深/浅背景、两侧檐角、柱头和门框实际Godot显示及4倍最近邻对照，确认没有改变已通过的连续造型；不把阈值处理称为一次新美术修复。
