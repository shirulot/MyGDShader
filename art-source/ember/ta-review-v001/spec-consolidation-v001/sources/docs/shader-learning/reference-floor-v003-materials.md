# v003 地板材质扩展标准

用户在v002实际实拼后反馈“好多了”，要求沿用该风格增加地图地板。此次保持已有构造，只新增浅灰控制区、深灰防滑检修区、锈褐旧仓区三种表面。原蓝灰仍是默认材质，四者可混铺。

| 固定项 | 标准 |
| --- | --- |
| 世界格／纹理格 | 32world／128texture |
| TileMapLayer缩放 | 0.25 |
| 示例相机zoom | 2 |
| 材质周期 | 1024texture，世界相位连续 |
| 压顶／南向立面 | 8world／32world |
| 默认桥范围／可见桥体 | 两格64world／40world |
| 接岸肩口 | 每侧12world |
| 外凸角／内凹角 | 复用固定上左光方向素材 |
| 像素与材质 | 低彩度、宽幅涂装变化、细小像素簇、稀疏磨损 |

新表面不能添加整格外框、阴影渐变或每格重复装饰。浅灰采用磨损环氧涂装，深灰采用低对比防滑短纹，锈褐采用低彩度氧化钢涂装；三份均为实际imagegen母稿，不由程序给旧图改色。

不同材质的地板仍共同计算一份占用与八邻接47型拓扑。`FloorMaterials`独立保存材质索引，不进入原生Terrain随机候选；桥口、压顶、立面和桥梁都只读共同占用。材质交界是同一连续平台，不能产生围墙或漏水缝。装饰板缝与栏杆保持独立组件。

验证纯材质变化必须触发脏区，局部结果必须与完整重建逐字节一致。材质索引必须随撤销、存档、场景保存、输入轮询和缓存签名保留；旧v2布局缺省原钢面。实际展示使用四张同构GPU场景及一张混铺场景，不能只交付母稿纹理。
