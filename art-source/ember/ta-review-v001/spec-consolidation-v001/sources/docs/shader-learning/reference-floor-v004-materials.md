# v004 地板扩展标准

沿用v002、v003的像素密度与共同构造，新增浅砂混凝土、青绿旧涂层、磨损灰白地砖，共七种可混铺表面。

| 固定项 | 数值 |
| --- | --- |
| 纹理格／世界格 | 128texture／32world |
| TileMapLayer.scale／相机zoom | 0.25／2 |
| 表面纹理周期 | 1024texture |
| 压顶／南向立面 | 8world／32world |
| 默认双格桥体／两肩 | 40world／每侧12world |
| 地形拓扑 | 共同Floor／Bridge两套47型 |
| 光照方向 | 固定上左光，方向角不旋转假代 |

各表面保留细小像素簇、大幅安静色块、低彩度和适量磨损。混凝土用矿物骨料与磨坑区分涂装钢面；青绿旧涂层表现露底与腐蚀；灰白地砖用齐平细填缝表现陶瓷铺装，不能使用厚外框、单块投影或夸张立体倒角。

`FloorMaterials`按目录稳定ID保存表面，不参与Terrain随机候选。材质变化不能改变共同占用、立面、压顶或桥口。世界相位固定，纯材质脏区、撤销、存档和场景重载必须包含材质ID；旧v3编号0～3不变。

成品必须提供可铺刷资源和真实GPU地图截图。验证新增3种与旧4种及相互之间的30个横纵交界case、四方向桥口、局部／完整RGBA一致性、材质保存／撤销与七格索引。结构验证不自动表示用户认可新材质艺术效果。

本轮上述验收已通过，四地图GPU实拼和三次真实材质更新通过；另修复同尺寸偏移bounds的缓存与派生TileMap原点，负原点(-3,-2)及恢复原点均与fresh全域六层RGBA一致。v004可以读取旧v2/v3文件；新ID 4～6须使用v004读取器。
