# 敌人序列帧生产规范 v001

依据已认可的四款敌人母稿、三视图及零件拆分图制定。当前批次为四款正向五动作的候选审阅稿：20 条序列、120 帧。候选生成、技术导出通过、原生美术完成与 TA 放行分别登记。

## 造型与朝向

低饱和旧工业像素风，浅装甲、蓝灰骨架和少量黄铜。角色自身右侧在正面图中位于画面左侧：巡逻兵右臂枪、工蜂右圆锯不可换边。工蜂严格四支腿与两条工具臂，重装严格双履带与单短炮，侦察机严格双风扇、双四叶转子及双电机。

朝向使用 `down/left/right/up`，每个方向独立制作并保留左上光照；左右非对称工具禁止简单镜像。首批制作 `down`，同一轻俯角正交镜头，原地播放；位移由后续游戏节点控制。

## 尺寸、锚点与像素

全部动作采用 128×128 透明画布，固定虚拟接地点 `(64,104)`，仅增加攻击、受击和倒地所需透明边，不放大单位本体。原样稿的画布、原锚点和主体上限分别登记，不能将整个画布当碰撞占地。侦察机锚点为恒定地面投影点，其悬浮和坠落只改变机身像素。

| 单位 | 原画布 / 原锚点 | 活动前主体上限 |
|---|---|---|
| 巡逻兵 | 64×96 / (32,80) | 40×64 |
| 切割工蜂 | 80×80 / (40,64) | 56×48 |
| 履带重装机 | 112×96 / (56,80) | 80×64 |
| 悬浮侦察机 | 96×80 / (48,56) | 64×40 |

布局参考每格为 512×512，目标画布为128×128；按行从左到右、从上到下编号 `f00` 起。生成器的实际输出尺寸与格内留白可能偏离布局参考，因此先等分固定源格，以f00中性参考姿态对照已认可的小图确定整条动作共用的 `cell_canvas_px` 缩放与 `offset_px` 注册位置，再用同一变换切出所有姿态。禁止逐帧按可见包围盒独立放大、居中或重新对齐，这会抹掉动作幅度并引入抖动。不通过代码重画、改色或填补缺失关节；首帧之外的定位偏差和体量漂移必须记录并在实际播放中检查。

## 动作与时序

| 状态 | 帧数 / FPS | 循环 | 关键要求 |
|---|---|---|---|
| idle 待机 | 4 / 4 | 是 | 0～1 原生像素轻动，最后接第一帧无明显跳变 |
| move 移动 | 8 / 8 | 是 | 双足交替 / 四足对角支撑 / 履带相位 / 双转子相位；不平移整机 |
| attack 攻击 | 6 / 10 | 否 | 准备→蓄势→释放→回收，f03记录视觉释放点 |
| hit 受击 | 4 / 12 | 否 | 中性→短促后缩或侧倾→恢复，白闪与粒子独立 |
| death 死亡 | 8 / 10 | 否 | 故障→失去支撑→塌落或坠地→残骸稳定，f07保持 |

攻击保持原工具：巡逻兵短臂枪后坐、工蜂圆锯短切、重装短炮后坐、侦察机现有光学传感器/底部探头锁定并短前倾；不新增导弹、机枪或特效。死亡优先关节折叠和机身塌落，保留组件唯一性，不能机身上和地上各复制一份。传感器可在死亡时暗下，但普通帧不烘焙强发光、子弹、烟、接地影或受击闪白。

## 导出与验收

每动作保留透明母稿、提示词、固定格逐帧PNG、图集、帧数/FPS/循环与锚点清单。Godot 使用 `SpriteFrames + AnimatedSprite2D`、`centered=false`、`offset=(-64,-104)`、Nearest；动作名为 `idle_down/move_down/attack_down/hit_down/death_down`。单次动作不配置成资源循环，死亡末帧保持。视觉事件只登记，不接入伤害判定或敌人AI。

正式实体像素遵循统一规范的二值 Alpha（实体 255、透空 0），连续 Alpha 的烟、光和受击特效另层。当前候选源 RGBA 原样保留；近不透明的 250～254 及轮廓半透明不能据此宣称正式像素验收通过，也不通过程序阈值处理掩盖源图问题。

核查帧数/顺序/真实alpha/越界/空帧/重复帧/共同画布与注册点，记录每帧可见范围、工具左右、部件数量、机体体量漂移和循环衔接。使用独立预览工程检查实际 Godot 播放，避免加载主项目单例。生图结果与切图检查通过只说明序列可播放，像素细化和动作美术验收另行记录；不把大图缩小等同于完成原生像素修整。

按 [TA 审查规范](ta-art-review-standard-v001.md) 提交固定版本母稿、完整提示词、1倍与4倍全帧联系图、实际播放和哈希。先审巡逻兵正向移动循环，确认头胸、工具、双腿刚性形状、接触/经过/抬升步相和闭环；通过后再放行其余动作或扩展方向。已经生成的其余候选可供比较，不能以数量齐全替代这一闸门。机械位置偏移、工具换边、腿与工具安装点互换、转子叶数漂移和死亡未落地均为具体美术返修项。
