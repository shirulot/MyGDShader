# 基础动作循环规范

用户要求：最终无限播放，尾帧与首帧必须自然衔接。播放器的loop开关不是视觉验收。

## 周期定义

- N帧采样覆盖[0,T)，最后一帧是T前的一个相位，下一采样就是首帧。不得在末尾再复制首帧造成双倍停留。
- 待机可按吸气与呼气往返组织。本版使用较稳定的源帧0、1、2、1，两个极点不连续复制。源F03的脸部和衣物漂移偏大，未继续使用。
- 行走和跑动必须完整经过左右两次换步，只正向循环。不能用倒放、交叉淡入或原地跳变掩盖缺失相位。
- 同时检查倒数第二帧、尾帧、首帧、第二帧的位移方向、速度变化、支撑腿、摆臂及遮挡顺序。

## 正式生产约束与本轮候选处理

正式生产仍受`docs/shader-learning/ta-art-review-standard-v001.md`第3节约束：同一可编辑母稿、固定格与全动作共同注册；不得用逐帧bbox居中、齐底或缩放掩盖源稿漂移。

下列位置与缩放处理描述v002候选的实际整理方法，并非对上述规则的替代或豁免。v002仍含逐帧头部定位与足底注册，不能据此声称通过正式固定注册验收。

- 固定64×96画布、共享调色板、根位置(32,80)、最近邻显示。
- 支撑帧足底注册至y80；跑动F03/F07是腾空相，足底注册至y77。整帧平移，不变形鞋底。
- 头部注册避免摆臂影响腰部包围范围引发全身水平跳动。生成稿的两排行间尺寸差整排统一校正，不逐帧拟合缩放。
- 检查二值透明、角色四邻域连通、画布边缘无裁切、每帧时长、尾帧非首帧重复副本。
- 连续播放至少10周期，再慢放与逐帧跨接缝。检查像素差只能定位异常，不能代替动作视觉验收。

最终自然度以播放画面为准；不能仅根据帧数、差分值或连通性宣称“完美”。当前候选不具有TA正式通过结论。
