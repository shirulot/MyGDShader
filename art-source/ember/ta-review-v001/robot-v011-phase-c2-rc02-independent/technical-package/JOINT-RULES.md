# 机器人关节与脚掌制作规则

基础是用户认可的v010关节修复方向；新增方向和动作须逐批检查，不能仅因采用同一流程就视为已通过。

1. **关节先有结构，再有动作。** 肩—上臂—肘—前臂—腕、髋—大腿—膝—小腿—踝—靴，各用固定源片和明确支点。肢体后方要有连续暗色内芯，甲片覆盖内芯，不能只把两个亮色块贴到一起。
2. **甲片和鞋不随帧变形。** 相邻帧使用同一片甲和同一只靴；膝踝改变角度，鞋掌保持完整块面。脚跟、鞋尖和鞋底不能在鞋身内部再折一次。
3. **支撑脚有固定位置。** 待机与采集的双脚保持原登记位置；步行按支撑、经过、触地相位移动。禁止逐帧按包围盒缩放、居中或自动齐脚，这会遮住真实漂移。
4. **像素归属必须明确。** 原母版中被遮挡的肢体先建立完整固定源；同一只手、护膝或靴边不能同时进入两条肢体并被分别带动。腰部需要的源像素重叠必须显式登记。
5. **补缝限于关节。** imagegen编辑只采纳允许区域；头胸、甲片轮廓、工具和靴保留原像素。背景光晕、额外碎点和改变比例的部分不进入最终图。不得用细线把错误浮点粘回角色。
6. **相同姿势使用相同接缝。** 采集下探与保持帧中，未移动的身体、腿和远臂复用像素。工具始终在解剖左腕；另一方向不能简单镜像。
7. **正背面独立考虑投影。** 向前伸手和屈膝不等于横向展开腿。S/N使用自己的纵向投影与幅度，避免膝盖左右撇开后看起来像断折。
8. **循环和回位也是动作的一部分。** 待机末首、行走末首、采集回待机都要看。采集末帧与同向idle首帧一致，切换不另造站姿。

验收同时看原生与4倍、浅底与深底、正常与慢速。单一alpha连通体只是技术底线；一条像素线连起来仍可能像断裂，必须实际观察关节形状、遮挡层次和动作中的连续性。
