# 切割机七向待机与受击 v023 / review v001

本批申请 7 个新增方向 × idle/hit，共 14 条、56 帧。正向 idle_down/hit_down 两条、8 帧从 v012 保留原字节；包内共 16 条、64 帧。128×128/root(64,104)/Nearest。待机 4 帧 4 FPS 循环，受击 4 帧 12 FPS 单次，末帧与恢复中性完全相同。

六方向使用 C22 的固定原图部件与髋部暗蓝灰安装座；C22 尚在单独审核，本批不继承其动作通过。SE 使用已通过 HC 首阶段的原固定骨架及原闭合前腿母稿，中性基准是该已通过的实际 rig_neutral_down_right，不退回遮挡不全的早期 SE 静态图。七套中性绑定均与各自注册源逐 RGBA 相同。

idle 机身位置依次 (0,0)/(0,-1)/(0,0)/(0,1)；hit 为 (0,0)/(-1,1)/(1,0)/(0,0)，表示屏幕水平方向的轻量碰撞回弹。腿、脚底及原工具零件形状不伸缩；脚底始终固定，机身与其所属双臂工具保持原相对位置。新增方向没有逐帧生图。被机身/工具遮住的足不伪造可见接地点。

本包保留 C22 六向部件归属、固定纹理连接件和原 SE 骨架的独立脚本。pilot_rig 的纹理加载改为直接读原 RGBA，从而支持未预先生成 import 缓存的干净运行；不修改原图、掩膜、比例或变换。首帧的源图零差验证确认装配保持一致。

技术自检：64 帧 PNG/图集/TRES、Alpha 二值、单连通、边界及原正向哈希；56 个实际姿态的四足固定变换、接地 Alpha、机身轨迹、恢复帧一致性；120 条 GPU 回对（112 新帧深浅底 + 8 旧帧）；32 个正常/慢速播放实例、16 次相位保持切换，idle 循环、hit 恰好结束一次。qa 中有深浅 1×/4×全帧和固定共同 ROI 的细节图。

打开 project.godot 可运行双栏审阅；export.gd、verify.gd、capture.gd 均从本包资源独立运行。此为待审候选，技术自检不替代总监对连接和动作自然度的独立判断。
