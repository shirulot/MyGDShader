## 独立光栅模型与保存 / 冷证据边界

独立双精度中心逆映射对正式导出存在 548 个逐帧像素差（idle 83、move 166、attack 130、hit 88、death 81），没有修改模型抹掉差异。其 547 次 Alpha 相同；另一次 attack f01 `(84,82)` 属 claw 的源 Alpha 边界。对全部 548 次做实际源及遮挡候选逆查，实际 RGB 都能追溯到同一绑定源的 3×3 最近邻候选，未找到脱离源区的颜色。

多数差异为前腿固定放大原稿 UV 整数行 / 列边界；例如中性右腿 UV.x = 1213 / 1311 / 1409、UV.y = 416，GPU 与双精度模型取相邻源行 / 列。两个大 RGB 差是 claw 在旧前脚排除边界压到新腿：attack f01 `(77,93)` 的 claw UV.x = 76.999382，实际为 canonical `(77,94)`；death f02 `(77,91)` 的 claw UV.y = 89.000840，实际为 `(76,88)`。唯一 Alpha 差 `(84,82)` 对应 claw UV.y = 83.999247，实际来自源 `(84,84)`。候选源边界距离最大约 0.02387 源 texel，属于独立模型不能逐点复现 GPU 插值 / 光栅取样的记录；不据此宣称 CPU 全 RGBA 与 GPU 等价，也不机械当作角色身份漂移。本轮保存的源 rig / PNG 对照提供实际渲染一致性证据。
