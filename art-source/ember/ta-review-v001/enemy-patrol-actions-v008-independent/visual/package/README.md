## 唯一美术根因修补

canonical的x76、y87–89三像素属于左夹爪内缘，却被旧left_knee_cap矩形取样同时包含。中性姿态相互重叠，姿态分离后膝甲带出悬空黑条。根据TA逆映射证据，将膝甲polygon在(76,87)–(77,90)处做一次凹口，排除这三像素；有效膝壳、夹爪、原始PNG和其余UV区不变。没有逐帧擦除、改脚、改枪或重新生图。

新膝甲多边形为 `(65,85),(77,85),(77,87),(76,87),(76,90),(77,90),(77,94),(65,94)`，详见 `rig.json`。动作关键姿态沿用已审方案。为统一可编辑来源，保留v006的一次上臂/前臂拆分；旧待机/受击上臂与前臂共同接受旧整臂的相同刚性变换，移动两者接受相同bob。
