## 实际关节与身份复审

逐帧检查两侧肩、肘、腕、髋、膝、踝，覆盖深浅底原生 / 最近邻 4×、完整角色与局部对照。F02 / F06 原有膝部水平切断明显缓和：上腿、关节盖、下腿之间形成可读的承接体积，没有仅靠一像素线连接。肩肘腕髋的承接厚度也成立；没有确认新的 P1 / P2 裂缝。

检查了新关节面片的宽度、亮面、轮廓与邻帧变化，而非只看补厚或 Alpha 连通。两半步及 F07→F00 对照未发现可定位的单帧掉块、突然换盖面设计或体积塌缩。修改仍是同一浅装甲、蓝灰结构和克制黄铜工具的角色；工具没有换侧或新增。

根在对照页检查正常 8 FPS 与慢速 2 FPS 的运行截图样本，并单步复核浅底 F02、F06、F07→F00 和深底 F03、F05；分审覆盖全部八帧。此处如实区分运行抽样与连续视频观察，不以播放轮数或播放器能运行作为流畅性结论，也不声称所有接入条件下绝无抖闪。

## 技术核验

独立固定包 / CRC / SHA 核对通过，八帧与送审哈希表及图集裁区一致，v009 对照取自原冻结包。独立重建关节遮罩和局部合成，2457 条逐点账本匹配；遮罩外全 RGBA 零改动，6014 个受保护部件归属像素零改动。头胸、双手、腕部工具的原可见像素保持。

实质改动每帧 286–328 RGBA 像素，新增不透明轮廓 39–52 px、清除旧轮廓 0–3 px。它是逐帧局部重画，不能误称所有关节轮廓完全未变；接受依据为上面的实际图像检查。

独立核对 16 张包内 GPU 与 16 张冷导入 GPU 对照、冷导入 `.ctex` 解码的完整图集和八区全 RGBA 一致，冷报告与 sidecar 哈希闭合。本轮没有再启动一遍 GPU；作者实际两轮播放记录为作者证据。独立 Godot 工程所需四条运行依赖均在包内。本机 Sharp 路径只影响重新构建源图，不影响已交付预览与运行素材。
