## P2：膝甲误带夹爪内缘，动作展开后露出悬空黑条

| 动作 / 帧 | 原生画布坐标（从 0 起） | 实际可见现象 |
| --- | --- | --- |
| attack f02 | (76,88–90) | 画面右侧夹爪内缘旁出现与主体隔开的 3 px 黑条 |
| attack f03 | (76,87–89) | 同一黑条继续悬空，其他相邻帧重叠隐藏 |
| death f04 | (72,97)、(71,98) | 侧倒时腿下出现孤立黑点 |
| death f05 | (66–68,102) | 腿下形成悬空短条 |
| death f06 / f07 | (63–65,102) | 完整残骸保持时，短条仍与主体分离 |

这是实际 PNG / 浏览器白底 4× 可见的轮廓问题，连通分析仅用于定位。独立逆映射确认这些像素均由 **left_knee_cap** 带出，其矩形源区误收 canonical 的 `(76,87–89)` 三个夹爪内缘像素；同样的源像素也在 left_arm_claw 中。中性姿态因重叠不明显，动作将错误归属暴露出来。不是枪臂拆分失败，也不应把黑条解释成有意脱落的残片。

最小返修：一次修正膝甲源 mask / UV 多边形，排除这三个非膝甲像素，保留合法膝甲体积，再统一重导 14 帧及对应预览、图集、GPU 对照。不要通过额外连接线、改脚、改夹爪角度或逐帧 bbox 对齐掩盖。旧固定包保留；若共享源修复影响先前三条动作，另出修补候选并提供增量，不覆盖原包。

复审检查黑条消失、真实夹爪与膝甲完整、中性首尾一致、死亡落地保持不变，及修改源区对已通过动作的影响。
