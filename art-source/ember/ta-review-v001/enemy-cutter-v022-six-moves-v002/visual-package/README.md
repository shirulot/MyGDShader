# 切割机六个新移动方向 v022 / review v002

申请 SW/W/NW/N/NE/E 六条移动、48 新帧。S 和已通过 SE 两条移动、16 帧保留原 PNG/图集；合计 8 条、64 帧。128×128、root(64,104)、8 帧/8 FPS 循环、Nearest。本候选尚未获得总监通过。

六个方向全部来自前置审核通过的固定静态母图。没有新增生成像素，没有镜像；中性 reset_bind 与本方向原图逐 RGBA 相同。源图、原八视图和其统一注册数据在 source/ 与 provenance/。工具、中心黄铜结构和机身保留固定源像素，机身只有 1 px 起伏。每条可见腿仅做整数刚体位移，不对甲壳做拉伸。

沿用已过 SE 的四足对角相位：front_left/rear_right 相位 0，front_right/rear_left 相位 4；每周期 depth `[2,1,0,-1,-2,-1,0,1]`、lift `[0,0,0,0,0,1,2,1]`。朝向投影决定屏幕位移。腿部可见程度按原母图保留：W/E 的远侧两足、NW/NE 的一条远前足被机身和工具遮住，不新绘幽灵足，也不将其当成已量测的可见落点。NW 另一前足只露上部，sole 明确为 null。其余落点由原腿选区最下方不透明像素注册，运动帧核对实际 Alpha。圆锯、夹爪不计为支撑腿。

原腿与机身的不透明像素唯一归属。每个髋部另加固定蓝灰纹理连接件：从本方向原图选定 2×2 暗蓝灰区域，用明确端点的四边形沿安装座运动，只在原部件后面填关节间隙，不伸缩浅甲或武器。中性绑定时这些连接件完全遮蔽，源图零差；动作中可见的新增连接像素登记坐标和源区域。`qa/pose_audit.json` 对 48 帧按源图及整数位移独立重建甲壳/机身 RGBA，并检查所有新增连接件像素处于固定端点四边形内且来自注册的暗蓝灰纹理；机身源像素、刚体变换、支撑点和可见脚底 Alpha 另行核对。`qa/pixel_audit.json` 核对 64 帧 PNG/图集、二值 Alpha、单连通、边界、6 个零差 bind 和保留帧原哈希。

GPU 回对共 112 条（48 新帧×黑白底 + 16 旧帧 TRES）；16 个 AnimatedSprite2D 以正常 8 FPS 与慢速 1 FPS 播完全部八帧并循环；八方向切换保持 frame/frame_progress。深浅底 1×/4×全帧联系图及共同 ROI(24,52,80,56) 的八帧细节图均在 qa/。ROI 导出时断言覆盖完整轮廓，包括两侧工具。

`project.godot` 直接运行双栏八向对照；`export.gd` 从固定源和 rig.json 重现六个新方向，保留动作不重绘。所有自检只验证技术证据，步态和连接自然度以技术美术总监的独立视觉审查为准。
