# 巡逻兵八向攻击与死亡 v026

本批新增七方向×attack/death，共14条98帧。正向两条14帧保持已过v012原文件；整包16条112帧。其余动作继续使用各自已过资源。

方向造型和腿部来自P20 v002、SE首轮过审绑定及P21 v003。W/E继续使用C002六张原source和已修正的刚性靴缘。每方向的同源固定身体遮罩再分出可见投射器前臂、夹爪；N源(75,82)从原腿段一次性归回投射器内缘。没有逐帧生图、镜像武器、绘制补丁或按各帧包围盒重对齐。静态neutral逐RGBA保持。

128×128，root=(64,104)，Nearest。attack6帧/10FPS单次：投射器前臂短促抬起/后坐，F03为视觉释放，F05回到原位；动作幅度沿用已认可正向。death8帧/10FPS单次：屈膝、收臂后侧倒，末两帧保持同一残骸。可见红色传感器在登记区域逐步熄灭，其余source RGB保持。该资源不包含游戏投射物、伤害和碰撞逻辑。

支撑分两阶段：死亡前三帧脚掌固定，后续整体绕固定登记轨迹倾倒，脚掌随身体离开原接触点，最终由折叠前臂侧缘或躯干/背包侧缘接地。rig.json保存一次登记的fall_origin_y_keys和源接触点；导出和播放不读取bbox修正位置。柔性髋膝踝连接段允许端点仿射，头胸、膝甲、靴及工具保持刚性。

前臂的短轴带是原source UV实例，实际RGBA逐点记录在qa/ownership_audit.json；不把所有短轴一概称为蓝灰或实体。近远侧腿按同源物理实例分别验证唯一完整归属。UV关节实例可以额外显露源像素，遮挡测点不强行补画。

project.godot可直接运行八向双栏正常/1FPS播放器。export.gd从固定零件重导；pixel_audit.py检查112帧/14绑定记录/旧正向；pose_audit.py核硬甲刚性、连接端点、真实画布接地及末帧；inspect_ownership.gd直接读取实际rig遮罩；verify.gd核210条GPU记录；capture.gd核32个播放器和16次保相位方向切换。所有作者自检均不替代独立TA回执。
