# 巡逻兵正左、正右移动 v021 / review v001

本批申请 W/E 两条移动（16 新帧）及其腿部补全造型审核。S/SE 两条移动、16 帧来自已通过的原文件；本包共 4 条、32 帧。SW/NW/N/NE 不在本批，选择时显示原静态图。本包属于候选，不代表总监通过。

## 原设定与新腿部

S002 的侧视图原腿靴互相遮挡，不能直接拆成两条闭合腿。本批使用一张 imagegen 固定双侧腿部零件母稿，exec `47d5045e-52e1-4cdf-b4ee-dcab347aad38`。每个朝向的原稿注册成 near/far 两个物理腿实例；二者复用同朝向零件是明确的结构复用。两个朝向分别取稿，没有左右镜像。注册是统一等比、Nearest、二值 Alpha，不改 RGB。源图、prompt、注册脚本和参数均在 source/，动作中不再逐帧生图或缩放角色。

此项会改变原已通过侧视图的双腿，**不是零差绑定**：W 中性图有 209 个 RGBA 像素变化，E 有 213 个；全部在固定腿区 `[50,78,27,27]` 内。原头部、躯干、手臂、工具保留，保护工具区域在中性及 16 个运动帧均逐像素验证。`qa/bind_original_candidate_2x.png` 每行分别 W、E；列顺序为原图、新绑定、深底原图、深底新绑定。浏览器和 Godot 的中性模式也使用同方向原设定对照。请独立判断补腿后是否仍满足既有造型比例和材质风格。

## 动作与核对

128×128、root(64,104)、8 帧 / 8 FPS 循环、Nearest。沿用原 down/SE 解剖左右的交替支撑与抬脚相位；朝向投影为 W/E。膝盖护板和靴子是刚体，只有蓝灰连接件做端点映射。body 保护手臂/工具并保持原像素。每个腿实例内部不透明源像素唯一归属且全部覆盖。F0 是走路跨步，真实中性图来自 reset_bind。

32 帧 PNG/atlas/TRES、Alpha 二值、边界及单连通通过。16 个姿态的刚体、工具像素、连接端点和支撑脚检查通过。48 条 GPU 记录为 16 新帧×深浅底和 16 旧帧 TRES 核对。8 个 AnimatedSprite2D 在 8 FPS / 1 FPS 各跑完 8 帧并循环；8 个方向切换验证相位或明确的本包外静态回退。

`project.godot` 可直接打开运行；`export.gd` 用本包固定素材重现动作，`verify.gd` 核对实时渲染，`capture.gd` 核对实际播放。原 S/SE PNG、图集完全保留。正式验收以技术美术总监对本冻结版本的回执为准。
