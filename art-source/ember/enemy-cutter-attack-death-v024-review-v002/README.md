# 切割机攻击／死亡 v024 / review v002

本批是候选：七个新方向 × attack/death，共14条98帧；正向两条14帧保持 v012 原始字节。整包16条112帧。14条新动作仍须技术美术总监独立审查。

128×128，root=(64,104)，Nearest。attack 6帧/10FPS，death 8帧/10FPS，均为单次播放。攻击 F3 为挥击最大幅度，F5 返回同一待机图；死亡末三帧一致，作为停尸帧。

六向固定源对应已通过 C22 母版；SE 使用已通过 HC 样片实际装配后的 neutral，与 C23 相同。每个方向只用一张固定128母版，通过明确的像素归属切出机身、可见工具、腿壳、脚掌。原图中的被遮工具继续保持遮挡，N 攻击通过机身横移、绕固定轴小角度蓄力和短促释放后回位表现，不能宣称所有方向锯盘都可见。

攻击工具绕注册肩轴挥动，锯盘在固定投影平面内转动。死亡机身下降7像素，腿壳绕注册踝轴向内折叠；蓝灰短轴带与SW锯盘主轴采用固定源区域的UV实例。脚掌变换固定，本批新方向的输出不越过 y=104；旧正向攻击的前伸工具保留原来的108像素下界。零件不逐帧生图，不镜像左右不对称的工具，不按各帧包围盒重新缩放或对齐。

静态绑定与七张固定母版逐像素相同。活动帧中，关节UV实例可能新增可见输出像素；脚掌可能被机身遮挡，固定变换不等于每一探针总能看到原脚掌像素。SE来源本身为过审装配图，不能称为未装配原设计稿。

打开 `project.godot` 即可运行双栏审阅入口；打开 `previews/index.html` 需通过静态HTTP服务，并将 `output/catalog.json` 作为该页同级 `catalog.json`。独立提交网页已绑定本包。
