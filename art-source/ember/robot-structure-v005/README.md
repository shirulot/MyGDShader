## 图上的改进原则

1. 胸架、腰部、完整骨盆横梁和双腿先形成连续承重骨架。
2. 肩轴嵌入胸架，外部肩甲覆盖轴体；肩甲下面存在真实的连接形体。
3. 肘套、膝套在相邻部件中套嵌搭接，弯曲时仍有厚度。
4. 动作围绕固定关节轴转动，同时重画遮挡和关节两侧形体，不把静态部件分别平移后拉杆补缝。
5. 中明度蓝灰用于表现可见的接头实体；内部暗缝收窄，避免黑带横切整条手臂或腿。
6. 黄铜工具固定在解剖左腕：正面为画面右侧，左侧面为近侧腕，背面为画面左侧。

三视图下方对比了细杆连接与有厚度的肘套连接。拆解图中外甲向周围展开，中央骨架保持连接；右侧细节展示肩轴装入胸架、肘部伸直/弯曲及髋膝的承重关系。
