# 巡逻兵移动 v003 · 实体覆盖材质候选

状态：PENDING_TA，尚未获得正式生产放行。本版仍仅为一个单位、一个方向、一个移动动作。v002及旧20动作包均保留。

本版与v002的姿态、九块源纹理区域、UV、关节、八相位及投影相同。原始source/canonical.png完全未改，SHA256为6e2c4eb57d214de69778291bcbdc4b40dfb4a5b4881fcb33338bb5f4474f348c。

画面处理增量是entity_cutout.gdshader：以0.5覆盖阈值规定实体像素的不透明覆盖率，RGB取同一源纹理。该规则作用于Godot材质，导出的八帧RGBA只含0/255 Alpha。它是透明度格式处理，不代表手工原生像素精修，也不能替代造型、轮廓与步态验收。原始RGBA继续保留供比较，未通过程序修改源PNG。

另修正骨段变换的数学对齐：沿原骨段自身轴缩短，再映射到当前骨段，保证源末端真实变换后与登记的目标关节相合。v002直接缩local Y在原骨段斜置时可能产生约半像素偏差；v003以矩阵端点误差小于0.0001校验。此项不改变步相和世界关节目标，也不根据bbox调整图片。

## 可编辑动作来源

rig.json登记九块纹理区域、UV、原生关節、遮挡次序和八相位；fixed_rig.gd从原始PNG创建Polygon2D零件。头胸骨盆为一块固定区域，枪臂在观众左，夹爪在观众右，整体仅随body_y在0/1/-1像素间移动。

腿关节采用同一组矢状面两骨几何，膝始终取前屈分支。相机投影y=104-0.75*height+0.35*depth；腿甲的骨段缩短属于已声明的二维投影近似，仍需TA确认没有不合理压扁或伸长。膝甲只归属小腿区域，足部包含原图已有踝袖以产生真实套叠，没有画补缝细杆。

128×128画布，root(64,104)，8FPS循环。角色左脚接触、下沉、右脚经过、抬升，再左右交换。每帧世界关节、投影髋膝踝、足底、对应地面点、support/lift与部件变换保存在output/catalog_v003.json。地面root不等于每一帧足部bbox下缘。

## 查看与复现

导入project.godot运行即可。preview.tscn展示八帧和8FPS/1FPS播放；空格暂停，方向键逐帧，R重播。preview.html读取同一atlas，提供1×/4×、黑白底、支撑点与地面投影标记。浏览器固定观察区域为(32,36,64,80)，不会修改128×128资产画布或各帧位置。

export.gd使用实际Godot渲染器生成八帧、atlas、SpriteFrames和catalog；audit.gd记录Alpha、8连通域、固定头胸区域逐字节比对；capture.gd实际播放8.4秒并登记正常及慢速遍历。qa/move_detail_1x.png与4x.png使用相同固定区域(40,48,48,64)。

本版八帧皆为二值Alpha、每帧一个8连通实体。只撤销已登记整像素body_y后，固定头胸ROI(54,52,20,25)对绑定姿态RGBA差异为0。连通性和局部ROI仅为诊断，不能证明关节厚度、腿甲体积或步态美术通过。

仍待TA判断：当前腿甲投影缩短是否合理、前后步幅/经过步是否清楚、膝踝套叠和首尾衔接是否自然、源参考像素簇与硬边轮廓是否达到本项目要求。仅在收到明确通过回执后扩展其他动作。
