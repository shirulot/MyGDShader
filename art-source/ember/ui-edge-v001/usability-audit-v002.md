# A稿UI可用性与扩展审计 v002

当前现场HUD、单台采能站详情够用。皮肤分层适合复用，完整游戏UI还需要新的控件和页面；没有必要为了扩展再生成整套皮肤。

## 覆盖与复用

| 用途 | 当前可直接复用 | 需要补充 |
| --- | --- | --- |
| 现场HUD、采能站详情 | 生命、计时、能量条、标记、状态行、抽屉、返回 | 显式注入真实数据并接选站 |
| 暂停、开始、结算 | 暗底、角件、按钮、Label、进度 | 页面组合、暂停/重试与场景切换 |
| 提示、确认框 | 文字背板、角件、按钮 | 通用弹层、确认/取消、焦点恢复 |
| 设备列表 | 行底、竖条、图标、肖像框 | 可点击行、选中/禁用、ScrollContainer与滚动条 |
| 设置 | 面板、正文、按钮 | 滑条、勾选框、下拉项、设置保存 |
| 背包、任务、区域地图 | 面板和选中皮肤 | 新玩法数据、物品格/页签/任务行/地图图层 |

18张PNG均为独立无正文皮肤；9宫格板、透明角件、固定端帽与填充裁切可以继续拼装。按钮已有normal/hover/pressed/disabled/focus，不需要为每个状态再画完整按钮。状态行是只读显示，四种采能图标不是通用可交互列表项。

## 实际发现并已修复

| 问题 | 修复 | 证据 |
| --- | --- | --- |
| 大有限能量使用Godot不支持的 `%e`，运行报错 | 用合法尾数/指数格式拼接，保留真实值 | reuse数量极值、布局科学计数 |
| 巨大秒数int64溢出，长倒计时越出角框 | 小范围转int，长时间紧凑格式，测字宽/裁切 | reuse 5999、6000、359999、1e300等 |
| 矮逻辑画布多生命与底栏相撞 | 按剩余高度预算折叠格数，并显示准确life/max | 70组实际布局；480/540真实截图 |
| 360宽抽屉按136排位却强制224宽 | 使用实际最小宽，窄剩余世界临时隐藏现场HUD | 360×640真实截图 |
| 断开设备/游戏每帧再次发送关闭 | close幂等，真实关闭才通知 | 重复20次refresh只通知一次 |
| 独立抽屉未入树close访问空viewport | 焦点操作检查入树状态 | 独立控件与reuse检查 |
| 普通Node数据源保留上一设备位置 | 无法投影则清除标记 | Node2D切换普通Node实测 |
| 无效标记坐标仍写入Node位置 | NaN/INF先替换成零并隐藏 | reuse入树前非法坐标 |
| 能量变化反复free/new生命槽 | 未变数据跳过，生命变只切Fill；数量变才增删槽 | instance_id稳定检查 |
| 运行时导出属性不刷新显示 | HUD边距/抽屉宽、标签/铜夹、适配器肖像同步更新 | reuse及widget检查 |
| Button禁用后仍有焦点及角层 | 下一帧释放禁用按钮焦点并同步角层 | widget报告保存原生before与after |
| 紧凑满条数字与100%可能相撞 | 留出8px间隔；超长数值省略 | 200/224px实际Label矩形 |

## 已验证的范围与限制

- 基准仍为720×720逻辑画布；实际检查360×640、480×480、540×540、720×720、960×540、1280×720，以及生命上限1/3/6/12和抽屉开关。项目的canvas_items物理缩放与主动改变逻辑尺寸不同。
- 完整布局建议逻辑画布至少480×480。360×640开终端优先显示抽屉，现场生命/时间/能量暂藏；收起后恢复。未测试所有任意屏幕比例，也未承诺低于480px高的完整抽屉。
- 480px高隐藏设备肖像，540px高缩小肖像；按钮与提示优先保留。长标题/目标使用省略，安全裁切不保证信息全部可读。
- 无文字进度条96px可用；默认带数字建议224px以上。短宽度仍能准确显示条比例和百分比，左侧长读数会省略。70组报告有26条限制说明：23处文字省略与3处64px请求被96px最小宽接住。
- 时间不足100分钟显示MM:SS，随后显示HHhMM；100小时起显示整天，10000天起短科学计数。长格式用于紧凑显示，原秒数不丢失；常规120秒倒计时保持原样。
- 字体来自系统回退，换字体需重测字宽。共享工厂仍本地覆盖字体/颜色，普通父Theme不能全面换肤。状态行、标记与抽屉仍绑定四采能状态和提示语。
- 适配器使用当前M0字段并默认max_life=3、目标380（可配置），不是所有游戏的万能适配器；跨SubViewport设备投影需另写转换。抽屉非模态，是否暂停/锁移动由玩法层决定。

## 扩展顺序

1. **先做配置入口**：样式Resource/Theme、项目字体、默认字号与UI缩放；保留A稿作为默认主题，避免大量硬编码脚本改色。
2. **再补通用控件**：带内容插槽的Panel、可配置图标/标签/颜色的行、可点击列表项、滚动条、Tab、Tooltip与确认弹层。现有PNG可继续使用，只有缺失形状需要补图。
3. **最后组装真实页面**：暂停、设置、开始/结算与设备列表。旧 `scenes/m0/ui.gd` 负责GameTimer引用和countdown_tick，替换画面时应先把计时迁到独立控制器，避免删除旧UI就停止倒计时。背包/任务/地图需实际玩法数据后再接。

常规245项、复用53项、控件68项共366项通过；70组布局几何错误0；12张真实Godot截图与两种宽度的进度像素检查通过。当前项目设置、M0源码和地图源文件与原baseline哈希一致。before报告保留失败历史用于对照，当前通过报告为不含before的文件。

Start-Process $uiGodot -WindowStyle Hidden -Wait -ArgumentList '--headless --path E:/dev/shader/godot-shader/godot-shader-simple --script res://tools/validate_ui_edge_reuse_v002.gd'
# 常规/控件/尺寸分别改script为validate_ui_edge_logic_v001.gd、probe_ui_edge_widget_v002.gd、probe_ui_edge_layout_v002.gd。
