## 来源与处理

`source/A-parts.png` 由 imagegen 参考既有 A 右下母版生成一次；提示词见 `prompts/A-rig-parts.txt`。原始生成文件为 `exec-dd61479a-dcbe-49ab-8d50-3dfc78f8edb2.png`。源图没有宣称是原生 64×96 像素画。

`prepare_parts.py` 只做静态连通部件裁切和透明通道清理，登记见 `parts.json`。源图把膝甲画在大腿和小腿两处，因此全帧共用的小腿取样区域排除上段，由大腿部件唯一呈现膝甲；靴子同样排除顶部插槽。没有逐帧裁切、重心居中、拉伸骨长或修改偏移掩盖源帧漂移。

绑定在 64×96 画布中合成；静态图层旋转并按固定骨段长度绘制。统一的最终量化步骤使用 alpha 128 阈值与既有 18 色表，实际输出 17 色。调试骨架不进入 PNG。这是分件下采样的方法验证，并未经过原生像素轮廓手工精修。

## 动作约定

- 根节点 `(32,80)`，8 帧，每帧 120ms，总长 960ms，正向完整两步；首尾不复制，不倒播。
- near 为解剖右腿/右臂，far 为解剖左侧。当前仅适用于这个固定视角。
- 大腿 12px、小腿 11px；二骨 IK 始终采用同一朝前弯曲分支。
- F0–F3 近腿支撑，F4–F7 远腿支撑。每周期世界位移 `(24,8.4)`px，与支撑目标相对身体的反向移动相抵。
- 上身有登记的周期性小幅 bob；不把腰部当世界根节点锁死。
- 页面移动背景是世界位移合成示意，非 Godot 集成。8 帧保持播放与连续背景移动之间仍可能产生量化滑动，数学采样点恒定不代表逐时刻脚锁通过。

## 验证与限制

- `qa/kinematic-check.json`：8 帧的双腿骨长误差约 8.9e-15；近腿支撑采样点叠加世界位移后重合。`qa/poses.json` 保存实际端点。
- `qa/export-check.json`：512×96 图集、8 个唯一帧、二值 alpha、17 个不透明色、无裁边、末帧不是首帧副本。
- 视觉：已查看八帧接触表，仍有纸片式旋转观感，髋部与手臂遮挡需要 TA 复审。固定骨长不能单独证明关节看起来正确。
- 循环：页面确实循环播放；尚未形成逐周期视觉验收记录，不声称“10 周期验收通过”。
- Godot 运行时、方向切换、碰撞、交互事件均未验收；本包不覆盖其他方向、A 待机或 C 跑步。
- 静态站姿在完全伸膝附近的 IK 钳制仅用于绑定观察，不作为可交付动画。

扩展条件：先通过本试样的步态、关节和身份检查，再制作 A 待机与 C 跑步，之后才扩展方向。失败的 v005 和原包保留用于追溯。
