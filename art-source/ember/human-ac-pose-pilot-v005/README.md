## 数据与方法边界

- `build_pose_guides.py`绘制全新骨架示意图，不处理原角色像素；`poses/*.json`为人工设计草案，不是从作者动画自动测量的骨架。支撑标签尚未逐帧校准，不得作为生产接触事件。
- 生图收到的是软图像参考；既没有硬性关节约束，也没有可编辑绑定源。生成结果没有严格遵守引导图的位置／比例，本轮只证明这种输入方法的效果与局限。
- `export.py`按固定行列切片，各段只用首格确定一次共同缩放和地面基准；没有逐帧居中、齐脚底、缩放或draw offset补偿。不是正式同一骨架注册通过。
- 透明度阈值210，固定18色量化，Nearest；三组PNG均64×96固定格。相邻格先隔离，防止透明留边采入其他帧。
- `identity.json`记录C原有八向可见性；旧提示词指定解剖学左侧耳机，正面和左向母版支持，但右下母版的远侧耳机可见性仍有疑点，八向身份不标通过。
