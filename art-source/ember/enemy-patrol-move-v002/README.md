# 巡逻兵正向移动 v002 · 固定部件候选

这是仅覆盖巡逻兵 move_down 八帧的返修小样，正式美术状态 PENDING_TA / NEEDS_NATIVE_FINISH。原20条冻结包未替换。原生Alpha保留，近不透明值仍含250～254，未做阈值或调色处理，不能视为最终生产完成。

直接打开本目录 project.godot。preview.tscn 同屏显示八帧及8 FPS/1 FPS播放。空格暂停、左右键逐帧、R重播。preview.html 为同一atlas的浏览器播放器，支持1倍/4倍、黑白底和语义支撑点叠加；显示时固定截取(32,36,64,80)以减少观察区空白，8帧完全相同且不改128×128导出画布。

## 可编辑母稿

- source/canonical.png 是已认可原生示例在128画布上的完整复制，SHA 6e2c4eb57d214de69778291bcbdc4b40dfb4a5b4881fcb33338bb5f4474f348c（哈希以 catalog 为权威）。
- rig.json 明确九块不可变纹理区域、原生关节位置、绘制遮挡次序、相机投影和八相位。修改母稿只需编辑这个 JSON 与 fixed_rig.gd，不再生成八份相似的独立角色。
- 头胸骨盆是一块固定区域；枪臂与夹爪臂固定各自一侧，只随躯干0/1/-1像素移动。腿甲与脚使用同一原始区域，膝关节只采用同一个前屈解，避免 IK 翻向。
- 矢状面世界关节经 y=104-0.75*height+0.35*depth 投影。足底支撑随原地行走的前后深度变化；摆动脚具有独立抬升量，不能把全部足底机械放在104。
- 腿部2D节点沿骨段缩短是已声明投影近似。它仍须通过实际像素与步态审查；源纹理区域不变不能单独证明刚性甲片的投影正确。
- 本轮新增内容是代码可编辑的游戏动画场景与引擎渲染输出，没有重新绘画、抠改、阈值化或改色原PNG。新增被遮挡关节绘画若有需要，应另行使用图像编辑工具保存来源。

## 导出与证据

export.gd 使用真实Godot OpenGL渲染器捕获128×128透明帧，拼为1024×128的8列atlas，统一root(64,104)。output 包含8帧、atlas、SpriteFrames和所有投影关节、支撑状态、变换记录。

audit.gd 使用固定头胸ROI(54,52,20,25)，只撤销已经登记的整像素上下移动，核对其与绑定姿态RGBA。全8帧此ROI差异均为0；这一局部指标不能代替全身美术审查。qa/move_detail_1x.png和4x是共同ROI(40,48,48,64)的观察条带，不改实际帧位置。

capture.gd 实际运行8.4秒，记录8FPS多轮及1FPS八帧遍历，保留Godot截图和来源atlas哈希。qa/pixel_audit.json、gpu_playback.json提供记录。

首次自查已修去膝甲分区重复取样，并将足部区域延伸至原图已有踝袖以实现关节套叠，没有画补缝细杆。已消除首次导出f03/f07相同的问题。剩余风险为腿甲投影缩短的像素观感、踝部连接、前后步幅是否充分，以及原始源Alpha/像素精修。全部交TA独立审查，不预先标记通过。
