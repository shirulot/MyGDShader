# A 右下行走 v009：恢复身体起伏，修正睁眼取样

针对用户反馈“身体和头部固定了，不要这样，之前的身体动得挺不错的，头部现在一直闭着眼”。范围仍为 A/down_right/walk 的8帧。

## 本次修改

- 恢复上身每一步的下沉、回升节奏：相对中位每4帧为 `0,+1,0,-1`px。头中心y为 `23,24,23,22`，胸中心y为 `42,43,42,41`，第二步重复。肩、手臂根部随胸移动，根节点始终 `(32,80)`。
- 这是骨盆以上的压缩与回弹；膝盖和脚的目标不随之增大。与 v008 逐项比较，两腿的髋、膝、踝坐标全帧相同。
- 源头部本来是睁眼。19px宽的贴图以中心定位时出现半像素左边界，直接从高分辨率源取样丢失眼白。现在先固定缩采样到19×20，再将贴图左上角落在整数像素坐标；头胸共用这个缓存方式，移动不重新抽取面部纹理。
- 没有重画或更换角色脸，没有生成新图；全部静态部件与 v008 相同。源图、提示词和原裁片登记继续随包保存。

- `qa/body-eye-check.json`：实际登记的头胸起伏为2px峰峰值、双腿轨迹一致、头部源文件字节一致。
- `qa/eyes-before-after.png`：旧版与新版实际PNG的面部放大对照。查看可见眼白，不以源图睁眼代替导出检查。

- 页面附 v008 同帧同速对照、正常/半速/四分之一速度和逐帧。
