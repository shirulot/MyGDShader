# A 右下行走 v008：步态重做

用户反馈 v007 “不自然”。本版继续使用同一组静态角色分件，重做腿的投影和受力节奏；仅 A/down_right/walk，不扩方向。

## 具体改动

1. 旧版在屏幕里强制大腿12px、小腿11px，前后摆动只能靠向右折膝。新版在角色前后运动平面内求解固定12/11长度，再做斜向投影；因此屏幕中的骨段长度可以合理缩短。投影系数为此试样的美术参数，不声称已经匹配完整八向相机。
2. 触地时身体略低、经过支撑腿上方时略高，并加入小幅前后重心运动。支撑脚目标独立于髋部；抵消重心位移后再求解关节，避免把脚拖走。
3. 摆臂使用与同侧腿反相的平滑周期，不再追随脚的回收曲线横甩。
4. 在有效取样区内登记静态安装点，见 `rig.js:mounts` / `qa/mounts.json`。这些是依据源分件形状估定的归一化位置，尚待TA确认；不可声称已完成原生像素手工精修。
5. 靴子在自己的小腿后合成，鞋口承接踝部，保留鞋体与鞋底；摆动期轻微转脚，支撑期平脚。远臂上臂仍处于躯干后，仅前臂按向前/向后位置改变遮挡次序，仍需审查穿身处。
6. 头胸静态纹理的绘制位置整像素取整，避免小于1px的重心运动导致高分辨率纹理重新取样闪烁；不对动画整帧作居中、齐底或注册修正。
