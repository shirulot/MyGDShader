# A / C 基础动作循环修订 v002

针对v001的尾首跳变和换步重复进行修订。A、C形象保持；只包含待机、行走、跑动的左侧视角，没有新增其他动作。

## 变化

- 待机沿用v001生成形象，改为完整吸气/呼气4相位，不在极点重复停留；剔除原F03偏大的细节漂移。
- 行走、跑动各8帧：按公开动作参考重新生成完整换步，并约束近远肢体遮挡。C采用A动作稿作姿势约束，保留C造型。
- 使用稳定头部参考定位，校正生成稿两排的尺寸差。支撑帧足底固定，跑动F03/F07保留3像素离地。
- 默认正向无限循环；专门提供尾首四帧、跳到尾帧、跨循环计数、慢放、逐帧与旧版对比。

每个角色待机4帧/1000ms、行走8帧/960ms、跑动8帧/640ms；合计40个导出帧，待机含复用的呼气姿势。

## 限定

这是针对循环问题的修订候选，不能仅以技术检查通过宣称完美。帧间仍有生成素材的衣物、脸部和体积细节波动；本轮未做像素级重绘统一，也不宣称精确复刻参考骨骼轨迹。64×96输出由高分辨率生成稿缩采样整理。

专项审查要求固定母稿与全动作共同注册；本候选仍采用逐帧头部位置与足底注册、分排尺度整理，不满足正式生产的固定注册证据要求，不替代TA规范，不登记为TA通过。

像素由imagegen生成；脚本仅切片、透明清理、共享限色、比例/位置注册和帧序导出。主游戏工程及v001交付包保留。第三方公开动作参考不随本包分发。
