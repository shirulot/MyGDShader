# 机器人朝下八帧行走小样 v008

本次交付是单方向行走候选，原生64×96，8 FPS，八帧一秒循环。技术保真和艺术结论分别记录，最终意见见 `qa/independent_art_review_v008.md` 及技术美术总监的版本审查。主玩法的正式角色资源没有替换。

## 制作方法

冻结原始母稿 `source/robot_idle_down_canonical_original.png`（SHA256 `c65f68455554edb03aea0a7b7b3cea6e1a779fa9d5aa49cba9b4aa5c4f6fbfff`），拆成23个可编辑层。头盔、胸甲、手套及解剖左腕工具在整条动作中复用各自源层。37个膝甲/胫端原像素调整了层归属，原坐标静态合成的1492个实体像素仍与原母稿精确相等。

按v005结构图一次定义17个隐藏结构、袖套及骨盆搭接面。护膝完整绑定，双膝上、下袖套随对应骨段；双腕增加固定三像素截面的搭接。26个明确枚举的原内部暗槽按 `core < sleeve < armor` 绘制，白甲和外轮廓保留在上。没有按逐帧透明检测来画填缝。

Godot使用固定三维关节长度求解腿链，再用同一斜俯镜头投影到二维原生画布：`screen = (X, Y + 0.65 Z)`。源装甲与袖套共享同一骨局部变换，投影可以改变可见纵向长度；横截面保持固定。该制作方式是固定源层和几何的2.5D像素渲染，隐藏面是一次作者定义的结构候选。

## 画布、脚底及播放

画布root固定为 `(32,80)`，世界地面为Y80。前后脚在不同深度，其屏幕脚底不必同一行。例如F00的两脚都触地，但投影脚底约Y82.08和Y77.92；实际接触像素单独记录。没有按动态bbox裁切、缩放、重新居中或齐底。

| 帧 | 步相 | 主支撑脚 |
| --- | --- | --- |
| F00 | 左脚接触，双脚触地 | 解剖左脚 |
| F01 | 左脚承重下降 | 解剖左脚 |
| F02 | 右脚经过 | 解剖左脚 |
| F03 | 右脚前摆 | 解剖左脚 |
| F04 | 右脚接触，双脚触地 | 解剖右脚 |
| F05 | 右脚承重下降 | 解剖右脚 |
| F06 | 左脚经过 | 解剖右脚 |
| F07 | 左脚前摆，接回F00 | 解剖右脚 |

前后步幅采用原地循环的局部坐标。pose中另提供匹配root前进量的诊断，不能据此认为已经和主玩法移动速度同步。转向、待机与行走切换、采集、其他朝向不在本次完成范围。

## 查看与复现

- `review.html`：正常8 FPS、慢速2 FPS、逐帧、母稿叠加、root/脚底和关节轴开关。通过本机服务打开 `http://127.0.0.1:8138/review.html`。
- `previews/`：1倍及整数4倍联系图、循环GIF/WebP、源像素映射诊断。诊断颜色不写入角色PNG。
- `frames/`：八张透明PNG，二值Alpha，固定11色。
- `robot_walk_down_atlas_v008.png`：512×96，八个64×96整格。
- `poses/`：每帧关节、骨长、支撑/触地、投影、可见部件来源及哈希。
- `godot-review/project.godot`：独立Godot审阅工程，真实SpriteFrames播放，提供原生1倍和4倍，不需要导入主工程。
- `fixed_rig_render_v008.json`、`fixed_rig_playback_v008.json`：渲染与实际播放证据。
- `qa/export_validation_v008.json`：编码、整格和放大保真核验。

在项目根目录可用以下命令复现源帧渲染；运行会更新本候选的帧和证据，复现后需要重新登记版本哈希。

```powershell
& 'E:/steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe' --path 'art-source/ember/robot-fixed-rig-v008/godot-review' --script 'res://render_fixed_rig_v008.gd' -- --workspace='E:/dev/shader/godot-shader/godot-shader-simple'
```

导出工具为 `tools/export_robot_fixed_rig_v008.cjs`，参数写在文件头注释。格式导出不会修改姿态或源PNG。

## 已知边界和证据解释

源层可见像素通过单独GPU owner-ID通道回溯原始UV。头胸及双手的可见映射没有未知样本；工具F01有两个逆UV采样边界仍登记Unknown，不能称为工具每一个像素都获得精确回溯。遮挡或投影取舍造成未出现的源像素也单列。

八帧当前透明实体接通只是局部结构诊断；正常速度的身份、步态、体积和末首衔接仍须视觉审查。编码、骨长、源哈希或单个连通域不能替代这项判断。

此前两份失效草稿保存在 `draft-01-pre-cap-affine/` 与 `draft-02-pre-wrist-cuff/`，保留问题证据；它们不是交付帧。v007也保留需修订结论。
