# v005 十材质地板统一标准

在已交付七种表面上新增旧沥青、砖红工业铺装、灰褐木栈道。原材质编号0～6和几何不变，新编号7～9分别对应道路、旧厂区和木制码头。

| 固定项 | 数值 |
| --- | --- |
| 纹理格／世界格 | 128texture／32world |
| TileMapLayer.scale／相机zoom | 0.25／2 |
| 表面相位周期 | 1024texture，即8×8世界格 |
| 压顶／南向立面 | 8world／32world |
| 默认双格桥体／两肩 | 40world／每侧12world |
| 拓扑 | 共用Floor／Bridge各47型 |
| 材质存储 | 普通source0、coord(id,0)，快照version3 |

平面纹理延续安静的大色块、低彩度、细小像素簇和适量磨损。沥青保持细骨料与浅裂纹，不混入道路标线；砖红铺装使用错缝砖与细灰缝，避免厚边框；木栈道使用水平灰褐木板与稀疏木纹，避免深黑间隙、厚侧面或板块投影。各纹理边界应保持相位连续，接缝只表现平面材料。

砖的生产单元128×64texture（32×16world），相邻行错位64texture；木板带高64texture（16world）。源稿实际数目通过真实接缝裁片校准为16行，每个艺术像素通过nearest采样保留，砖的跨周期半块循环衔接。此注册属于切片与拼装，不用程序画线或重新生成材质颜色。

刷任何材质都保持统一占用、外压顶、立面和桥口，不能在材质交界制造内墙。混铺场景必须实际包含十种表面。新三种与旧七种及相互两两之间共24对，横纵48组交界必须维持同一coverage；验证四向桥头、局部／全域六层RGBA、撤销存档、场景重载、旧ID兼容、负原点重建和显示格位置。

旧数字键保留，新增F1／F2／F3，方括号循环十种材料；单材质地图运行即选中对应笔刷。技术通过仍需用户检查新增美术效果。

上述本轮独立suite已通过：48组交界、12个桥口、12次全域RGBA对照、旧七份表面冻结比较、实际快捷键路由与504个偏移格映射；四场景实际GPU与三次纯材质更新通过。目录编号、纹理源与实际执行代码SHA保留在报告。
