# 人类工业作业者 v001

用户选择先用公开预览制作人形母版与动作试样。本批独立于旧机器人，不替换主工程。

交付：三视图造型母稿、左/正/背64×96整理预览，以及左侧待机7、行走8、跑动8、下蹲6，共29张动作帧。完整匹配仍需原始素材包，当前只完成四组公开预览试样。

- 查看 `preview.html`：模板与新角色同序号帧对照、慢放/暂停/逐帧、三视图、全动画台账。
- `previews/all-actions.gif`：四组动作总览。
- `frames/`：固定64×96透明PNG，角色三视图和四组动作分开。
- `previews/*-strip.png`：固定横排图集。
- `previews/*-normal.gif`、`*-slow.gif`：动画；透明版本为 `*-transparent.webp`。
- `character-standard.md`：造型、配色、画布、关节和全动画匹配规则。
- `animation-inventory.json`：95条公开清单记录，包含组合条目，不等同于源包标签数量。

## 来源和方法

动作研究来源：https://deadrevolver.itch.io/pixel-prototype-player-sprites

通过内置 imagegen 生成三视图母版及四个动作；行走第一版后半排转向错误，保留在 `source/walk_rejected-generated.png` 作错误记录，未导出采用。最终行走用第二次姿势迁移稿。实际提示词在 `prompts/`，生成来源清单见 manifest。

整理脚本 `finish.py` 只执行固定区域裁切、每组统一缩放、鞋底注册、12色量化、透明清理与导出，不程序绘制人体关节。下蹲源稿两排并非等高分隔，已按真实留白分界切片，避免上排鞋底混入下排。

原公开GIF解码后的帧时长为：待机100ms×7、行走120ms×8、跑动80ms×8、下蹲100ms×6。本批按这些时间播放。未取得原包，因此不能将GIF解码帧序等同于Aseprite源标签，也不声称人体骨骼轨迹已精准复刻。

## 检查与限制

29帧均在64×96内，使用二值透明和共享色板，当前每帧整体四邻域连通。落地帧实体末行y79，跑动选定离地相末行y76。技术报告在 `qa/validation.json`。

可视上为同一人类工作服家族，全帧朝左；行走和跑动的近远腿交换、服装局部闪动以及母版与动作之间的比例差异，仍需观看判断。连通检查不证明关节自然。当前为设计试样，不是逐帧严格复刻或用户验收通过的成品。

完整动画任务已登记但未执行其余条目。待取得源包，可逐标签对齐帧数、时长、循环方式、事件点、武器连接点和根位移。当前无八向扩展、武器/特效素材或Godot运行替换。

ZIP只含自制角色、提示词、规范及报告，不含第三方动图和付费资源。项目内完整网页使用本地研究参考，ZIP内不包含该网页。
