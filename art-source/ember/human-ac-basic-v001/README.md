# A / C 基础动作试样 v001

本轮只增加待机、行走、跑动，不增加扩展动作。两个角色分别4+8+8帧，共40帧，方向向左。预览页 preview.html 支持动作切换、正常/三分之一速度、暂停、逐帧、接地线。

## 交付内容

- frames/：64×96透明PNG单帧。
- final/：每个动作的水平图集和帧数、时长、根位置JSON。
- previews/：正常与慢放透明WebP/GIF、深色背景GIF；overview.gif为六组总览。
- source/、prompts/：内置imagegen源图、来源记录和提示词。
- qa/：尺寸/连通性检查、联系表、浏览器截图和视觉审查。

## 制作与验证

使用内置imagegen按动作生成，参考已选A/C形象和此前保存的Dead Revolver公开动作预览。源稿按人物连通区域切片；每个动作内固定缩放，使用最近邻缩采样、共享18色与根位置(32,80)。不通过代码绘制或补画肢体。清理了A行走F05缩采样产生的两个单像素浮点。

检查40帧尺寸、二值透明度、裁剪边界、主体四邻域连通性以及GIF时长；浏览器检查三种动作切换、正常和慢放、逐帧控件。技术连通不代表人体运动已通过视觉验收。

## 当前限制

这是基础动作试样，尚未得到用户动画验收，不应视为最终生产资源。部分帧近远腿交替不够清晰，跨动作脸部、服装和躯干体积仍有轻微漂移；步态不是对参考的精确骨骼轨迹复刻。输出为64×96缩采样整理帧，不宣称原生像素手绘。
