# v004 全身位移修正

针对用户反馈“v003 左还可以，其他动作大幅度的不该有的全身偏移”。

本次修正42段非左向待机/行走/跑动的播放定位；保留全部16段左向动作。58张PNG图集与v003字节完全一致，帧序、帧时长、角色局部像素均不变。**修正信息在每段JSON的 `draw_offsets`，使用PNG时必须同时使用该数据。**

查看：http://127.0.0.1:8158/revisions/human-ac-registration-v004/preview.html

## 原因和修法

v003导出使用源图等分列中心和每行共同地面基线。生成图中的人物身体中心并未遵守这些格坐标，导致逐列漂移和F03→F04的排版换行跳变。运动姿势本身还存在身体转角、尺度变化，这是另一类问题。

`waist-landmarks.json`人工登记336帧的腰带/骨盆中心，坐标来自64×96诊断帧，约有1–2px读数误差。各帧通过整数draw offset把同一腰部标记登记在固定x=32处。待机腰部y固定；走跑使用前后半步对应高度的平均周期，步行起伏限制为中心±1px、跑动±2px。没有逐帧bbox缩放、脚底齐底、头顶对齐或改变人物局部结构。最大单轴修正8px。

这属于动画注册修订，不是源图关节或造型修复。骨盆锁定会抑制真实的侧向重心摆动；当前优先解决用户指出的整身平移，仍需结合支撑脚与转角进行视觉复审。腰部标记范围归零是算法约束，不是动画整体质量的独立证明。

## 使用

渲染每帧时，把相应 `draw_offsets[frame]` 加到原绘制位置；节点世界位置不变。例：`draw_position = actor_position - Vector2(32,80) + Vector2(dx,dy)`。图集仍为64×96格。偏移后的可见内容可能伸出原64px格边界，绘制区域不得按原格裁剪；预览两侧各留16px显示边距。

`build.py`可复现偏移数据与前后对照图，输入为v003图集和手工标记。生成的联系图/动图是播放位置模拟，并非新的生产PNG。`preview.html`以同一时钟显示前后版本，提供尾→首单步、辅助线、正常/慢速与深浅背景。
